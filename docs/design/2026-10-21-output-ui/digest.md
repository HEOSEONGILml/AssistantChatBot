# UI 구현 다이제스트 (docs/design/2026-10-21-output-ui)

아트보드 18개와 README에서 구현에 필요한 값을 뽑은 것이다(2026-10-22). 원본과 어긋나면 아트보드와 README가 우선이다.

아트보드 캔버스: 440x640 (큰 창 12번만 960x640). 캔버스 배경(#E6E9EE), 가짜 바탕화면(#F7F8FA 박스)·작업 표시줄(#20242C, 높이 48px)은 목업용이므로 구현 대상 아님. 구현 대상은 강아지, 패널, 큰 창.

## 2. 전역 레이아웃

강아지 창 (목업 좌표 기준, 처음 위치는 화면 오른쪽 아래 작업 표시줄 위. 끌어서 옮길 수 있음 — 20·21번):
- 96x72 영역, `right: 20px; bottom: 48px` (48 = 작업 표시줄 높이). 클릭하면 패널 토글(`aria-expanded`).
- 스프라이트: 시트 `background-size: 768px 648px`, `image-rendering: pixelated`. 프레임 64x48 이 1.5배 = 96x72 (8열x9행). 패널은 `bottom: 132px` (= 작업 표시줄 48 + 강아지 72 + 12).
- 배지: 강아지 영역 안 `left: 6px; top: 4px`(왼쪽 위), 가로로 `gap: 2px` 나열. 알약형 `min-width:22px; height:22px; padding:0 6px; border-radius:999px; border:2px solid #FFFFFF; font 12px/700 white; line-height:18px; center`. 순서 빨강(2)→노랑(1)→초록(2). 개수가 0인 색은 안 보임(추정: 아트보드는 있는 색만 그림). 로그아웃 상태는 배지 없음.
- 툴팁: 마우스를 올렸을 때, 강아지 왼쪽 위 `right:124px; bottom:64px; padding:6px 10px; radius 8px; bg #20242C; color #FFF; 12px; nowrap`. 문구: 작업 없음 "눌러서 일 맡기기", 일하는 중 "일하는 중 · 작업 2개". (배지 있을 때 툴팁은 아트보드에 없음)
- 말풍선 없음.

패널:
- 너비 340px, 강아지 위 12px 간격: `right: 20px; bottom: 156px` (=48+96+12). 강아지 오른쪽 정렬. 아래쪽에 꼬리(강아지를 가리킴).
- 높이: 탭 목록 화면은 내용에 따라 자람(헤더 44px + 행 4줄 x 44px + 페이저 36px + 추가 버튼 영역 56px). 작업 대화 11번은 `height: 440px` 고정, 스케줄 대화 16번은 `height: 460px` 고정. 대화 탭 18번은 본문 `height: 360px` + 입력줄.
- 닫기: 패널 머리의 ✕ 없음. 강아지를 다시 누르면 닫힘.
- 탭 바(`role=tablist`, `padding: 0 4px 0 8px`, 아래 1px #E6E9EE): 순서 **알림 · 대화 · 작업 · 스케줄 · (사용량 아이콘) · (설정 아이콘)**. 텍스트 탭 4개(알림·대화·작업·스케줄)는 `padding: 0 6px; min-height:44px; 13px`, 선택 시 700 + 밑줄 2px #1B1F27 + 글자 #1B1F27, 비선택 500 #5B6472 + 투명 밑줄. 아이콘 탭 2개는 `width:36px`, 16x16 svg(stroke 2). 사용량 아이콘 = 막대그래프(`M3 3v18h18`, 막대 3개), 설정 아이콘 = 톱니(circle r3 + gear path). aria-label "사용량", "설정". 탭 바 오른쪽 끝에 **크게 보기** 아이콘 링크(36x44, #5B6472, 15px 대각 화살표 `M15 3h6v6` `M9 21H3v-6` `M21 3l-7 7` `M3 21l7-7`, aria-label·title "크게 보기"). 누르면 패널 전체를 큰 창(12번)으로 띄우고 작은 패널은 닫는다 (사용자).
- 알림 탭 라벨 옆에 성격별 미니 배지 (10px/700, min-width 13, padding 0 3px, line-height 14, 간격 2px): 빨강 2, 노랑 1, 초록 2 (알림 탭 라벨은 "알림&nbsp;" + 배지들). 다른 탭 화면(작업/스케줄)에서도 동일하게 알림 탭에 배지가 붙음. 로그인 필요(10번)에선 배지 없음.
- 페이저: `1 / N` 가운데, 양옆 화살표 44x36 (이전/다음 페이지, 첫 쪽에서 이전은 disabled #C4CAD3). 위쪽 1px #E6E9EE. 한 쪽 4줄.
- 하단 추가 버튼 (작업·스케줄 탭만): `padding:8px; border-top`, 버튼 `min-height:40px; border:1px dashed #C4CAD3; radius 10; 13px/500`, "+" 아이콘 + "새 작업" / "새 스케줄".

큰 창(12번): 패널 전체를 크게 띄운 별도 창. 880x544 창 (캔버스 960x640 안 `left:40; top:24`), 흰 배경, 테두리 1px #C4CAD3, radius 8. 구성: 제목줄 36px (#F3F4F6, 텍스트 12px "패널", 최소화·최대화·닫기 44x36) → 탭 바(padding 0 16px, gap 4, 텍스트 탭 6개 모두 글자: 알림(+배지 11px/16) · 대화 · 작업 · 스케줄 · 사용량 · 설정, 14px, padding 0 10px, 선택은 작은 패널과 같음) → 본문 두 칸: 왼쪽 300px 목록(행 48px, 선택 행 bg #E3ECFF + 굵게, 페이저, 맨 아래 [새 작업] 점선 버튼), 오른쪽 선택한 대화(머리 padding 10px 20px: 제목 16px/700 + 부제 12px, 오른쪽 [멈추기] min-height 36 / 대화 기록 padding 16px 20px, gap 10, 14px, 말풍선 max-width 75%, 진행 단계는 펼친 박스 / 입력줄 padding 10px 20px, textarea 44px 시작 max-height 140, 보내기 44x44). 예시 화면은 작업 탭에서 "휴지 주문"을 고른 상태.

## 3. 아트보드별

공통 대화 입력 키: Enter 보내기 / Shift+Enter 줄바꿈, 보낸 뒤에도 커서 유지 (README).

**1 Main.dc.html — 작업 없음**: 강아지 앉기(sit, row1). 툴팁 "눌러서 일 맡기기". 배지 없음. 클릭 → (목업 링크) 새 작업 입력; 실제로는 패널 열기.

**2 Progress.dc.html — 일하는 중**: 강아지 걷기(walk, row4). 툴팁 "일하는 중 · 작업 2개". 클릭 → 작업 탭.

**3 Question.dc.html — 답이 필요함**: 강아지 조르기(beg, row7), 빨강 배지 "1". aria-label "작업 패널 열기, 답이 필요한 질문 1개". 클릭 → 알림 탭.

**4 Result.dc.html — 새 소식**: 강아지 서기(stand, row0), 초록 배지 "2". 클릭 → 알림 탭.

**5 Failed.dc.html — 못 함**: 강아지 엎드림(lay, row2), 노랑 배지 "1". 클릭 → 알림 탭.

**6 Input.dc.html — 새 작업**: 패널 (탭 바 없음). 머리: 뒤로(‹ 44x44, "작업 목록으로") + "새 작업"(14px/700). 폼 padding 12px 16px 14px, gap 8. 라벨 "무엇을 할까요?"(12px/700 #5B6472). textarea `height:160px; padding:9px 12px; border:2px solid #1D4ED8; radius10; 13px/line-height 20px; resize none; overflow-y:auto`, placeholder "예: 아까 슬랙에서 본 링크, 카톡으로 민지한테 보내 줘" (긴 글 예시 채움). 아래줄: 힌트 "Enter 보내기 · Shift+Enter 줄바꿈"(11px #5B6472, flex 1) + [취소](border 1px #C4CAD3, min-height 40, padding 0 16) + [맡기기](bg #1D4ED8, 흰색 13px/700). 취소·뒤로 → 작업 탭. 강아지는 서기. 강아지 클릭 → 패널 닫기.

**7 Alerts.dc.html — 알림 탭 (혼합)**: 강아지 조르기, 배지 빨강2 노랑1 초록2.
- 맨 위: 첫 번째 질문만 카드 (`margin 10px 12px 0` 영역 안, padding 10px 12px, border 2px solid #C81E1E, radius 12, 13px). 카드 구성: 1줄 `**휴지 주문**(500) · 내 요청`(#5B6472) + 오른쪽 시각 "09:12"(12px); 질문 본문 "평점 4.6점, 리뷰 1만 2천 개예요. 결제할까요?"(14px); 버튼줄 [결제](주 버튼 36px radius 8, 700) [취소](보조) 그리고 오른쪽 끝 "대화 보기 ›"(링크, 13px/500).
- 아래 목록(행 min-height 44, 16px 아이콘, gap 8, 이름 500 + `· 요약`, 하단 1px 구분선). 행 필드: 상태 아이콘 | 이름 + 부가 문구(말줄임) | 오른쪽(버튼 또는 시각 44px 너비 가운데 12px):
  - 질문 한 줄: 빨강 원 "?" 아이콘("답을 기다림"), "링크 카톡 전송 **· 민지가 두 명이에요. 누구?**"(#B42318), [답하기] 버튼(min-height 32, margin 6px 4px, padding 0 10px, bg #1D4ED8, 12px/700, radius 8).
  - 못 함: 노랑 원 "!" 아이콘(배경 #FEF3C7, 느낌표 #B45309), "보고서 업로드 `스케줄`(#0F5F52) · 못 했어요", 시각 "10:30".
  - 다 함: 초록 원 체크 아이콘(배경 #E3F4EA), "메일 요약 `스케줄` · 다 했어요", "09:04".

- 클릭: 카드의 "대화 보기 ›"·[답하기] → 작업 대화(11). [결제]/[취소]는 답을 보내는 버튼.

## 7. 강아지 자세 → 스프라이트

manifest: image `/sprites/dog/dog-02.png`, frameWidth 64, frameHeight 48, scale 1.5, facing "left". 시트 768x648 (스케일 1.5 기준 8열x9행, 원본 512x432). 아트보드도 1.5배다.

## 8. 모호함 / 불일치

1. ~~강아지 크기~~ → 1.5배(96x72)로 줄였다 (사용자, 2026-10-22). 아트보드와 manifest `scale: 1.5`가 같다.
2. 배지 색 이름: README는 "빨강·노랑·초록" 값을 안 줌. 아트보드 값 #C81E1E / #B45309 / #15803D 사용. 질문 글자 색 #B42318(빨강 글자)과 정지 아이콘 #B42318은 다름(#C81E1E는 배지/카드 테두리). README "정지 아이콘이 빨강이라 '답 필요' 빨강과 겹친다"는 미결.

5. 툴팁: 배지 있을 때·로그아웃 때 툴팁 문구는 아트보드 없음 (README "아직 정할 것": 배지 내용 풀어쓸지).
6. 스케줄 요일 칩은 "매주"일 때만 아트보드에 있고, "매월" 날짜 칸은 아트보드 없음 (README는 존재 언급).
