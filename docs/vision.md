# 제품 비전

사용자가 컨셉을 공개하는 만큼 누적한다. **확정**은 사용자가 직접 말하거나 확인한 것이다. 확인받지 않은 해석은 "Claude 판단"이나 "가정"으로 따로 적는다.

다마고치 시절(2026-10-14 ~ 10-20)의 비전은 git 기록에 있다 (`git show 4b8c747:docs/vision.md`).

## 핵심 컨셉: 조수 (확정, 2026-10-21)

- 프로젝트 성격을 **다마고치에서 조수로** 바꾼다. → [0022](decisions/0022-pivot-to-assistant.md)
- 강아지는 돌아다니지 않고 **화면 한 자리에** 있다.
- 사용자가 **도움을 요청하면** 강아지가 대답하거나 **실제 작업을 처리한다**.
- 방향은 일반적인 **computer-use 조수**다. 다만 처음부터 복잡한 기능을 넣지 않는다.
- **첫 기능은 인터넷 브라우저 제어**다.
- 조작 대상은 따로 띄운 브라우저가 아니라 **사용자가 지금 보고 있는 브라우저 창**이다.

## 없애는 것 (확정, 2026-10-21)

- 기분과 반응.
- 찌르기·쓰다듬기·던지기 등 **강아지와의 상호작용 전부**.
- **웹 버전**. PC 앱 하나로 간다.
- 지금 있는 **Jev 기능 전부**. Jev는 구조를 만들어 가며 필요하다고 판단되면 그때 쓴다. 필요 여부는 만들면서 알게 된다 (사용자).

## 에이전트를 만드는 순서 (확정, 2026-10-21)

- **1단계: Claude Code로 구현한다.** Claude Code라는 완성된 에이전트 제품을 그대로 쓴다.
- **2단계: Claude Code 부분을 직접 설계한 에이전트로 대체한다.**
- → [0023](decisions/0023-claude-code-first-then-own-agent.md)
- Claude 판단 (확인 전): 2단계에서 갈아 끼우기 쉽게, Claude Code는 두뇌 안의 한 곳(외부 호출 계층) 뒤에만 둔다. 화면과 프로토콜은 Claude Code를 모른다.

## 기억 (확정, 2026-10-21)

- 조수는 **기억한다**. 예: 아침에 찾게 한 상품을 오후에 "아까 그거"라고 해도 알아듣는다. 무엇을 얼마나 기억할지는 아직 정하지 않았다.

## 할 일로 남기는 것 (확정, 2026-10-21)

- **먼저 도움 건네기**: 강아지가 작업 중인 창을 들여다보고 먼저 도움을 건넨다. 처음 목적에 있었지만 이번에는 넣지 않는다.

## 플랫폼 (확정, 2026-10-14)

- **Windows PC를 먼저** 만든다. → [0022](decisions/0022-pivot-to-assistant.md)
- Android는 사용자가 지시할 때 별도로 한다.
- **두뇌는 화면에 의존하지 않는다** (2026-10-15). → [0022](decisions/0022-pivot-to-assistant.md)

## Claude 판단 (확인 전, 2026-10-21)

- 강아지 **모습은 남는다**. "강아지가 화면 상 한 자리에"라는 말에서 짐작했다.
- 브라우저는 **크롬·엣지 같은 크로미움 계열**부터 지원한다. 사용자가 기술 선택을 위임했다.
- 되돌릴 수 없는 동작(결제·전송·삭제) **직전에만 확인**을 받는다. 사용자가 이 질문을 건너뛰어 잠정으로 정했다. 설계 때 다시 본다.
- Tauri 화면과 파이썬 두뇌 구조는 그대로 쓴다. 두뇌 속은 새로 짠다.

## 아직 정하지 않은 것

- 첫 버전이 "됐다"고 볼 요청 하나 (성공 기준).
- 조수의 말투·성격.
- 화면 어디에 강아지가 있는지, 대답을 어떻게 보여 주는지.
