# 시뮬레이션으로 말하기 보정값 맞추기 (2026-10-15)

두뇌 v2 구현 Task 9. 대표 상황 144가지의 실제 Jev 응답을 녹화하고(`brain/sim/jev_recording.json`), 가상 사용자와 함께 확률 모델만 돌려 이벤트 종류별 말하기 보정값을 맞췄다. 재현: `brain/`에서 `uv run python -m sim.record`(녹화), `uv run python -m sim.simulate --fit`(맞추기), `--days 14`(보고).

가상 사용자(잠정값): 평일 9~18시 자리에 있고 12~13시 점심으로 비운다. 분당 메시지 3%(보내기 전 타이핑 2번), 찌르기·쓰다듬기 0.5%, 던지기 0.2%. 강아지가 말하면 절반은 답한다. 자리를 비우면 30분마다 조용함 이벤트.

## 결론

| 목표 (평균 성격) | 결과 (14일) |
|---|---|
| 타이핑 중 끼어들기 15% | 14% |
| 메시지에 답하기 85% | 85% |
| 조용할 때 먼저 말 걸기 33% (10분마다 → 30분에 한 번) | 38% |
| 말하면 이어서 2번 이상 30% | 28% |
| 보정 뒤에도 Jev 1위 반응 유지 ≥ 60% | 100% (유형별 85~100%) |
| 기분이 0.9 이상·0.05 이하에 머무는 비율 ≤ 20% | 6% (활발 유형 20%) |
| 8주 뒤 기준값이 새로 한계에 붙은 강아지 0 | 0 / 20 |

- **맞춘 보정값**: typing −4.28, message −0.71, dog_spoke −2.13, quiet −2.61 (`tuning.py` 기본값).
- **유형별 차이가 뚜렷하다**: 끼어들기 과묵 4% < 평균 14% < 활발 32%, 먼저 말 걸기 17% < 38% < 55%. 예민·성마름 유형은 가장 과묵하다(분노·시무룩 기준값이 말수를 줄임).
- **무작위 100마리**: 끼어들기 2~31%(중앙 13%), 답하기 49~93%(83%), 먼저 말 걸기 11~53%(31%), 연달아 7~48%(25%). 극단(0%, 50%+ 끼어들기)은 없다.
- **성격 변화**: 8주 동안 기준값은 중앙 0.06, 최대 0.22 움직였다. 강아지 사이 차이(표준편차)는 0.096 → 0.107로 개성이 유지된다.

## 시뮬레이션이 찾아낸 설계 문제와 고친 것

| 발견 | 고친 것 |
|---|---|
| 수다스러운 강아지일수록 오히려 먼저 말을 덜 걸었다. "연달아 말한 횟수"가 사용자 입력 때만 0이 되어, 한 번 3번을 채우면 사용자가 입력할 때까지 조용함에도 말하지 못했다 | 연달아 말하기는 한 흐름 안에서만 센다: `dog_spoke` 외의 이벤트가 오면 0으로. 답 기다림 표시는 사용자 입력 때만 풀린다 |
| 8주 뒤 거의 모든 강아지의 들뜸 기준값이 0.4→0.8, 심심함 0.6→0.3으로 같은 성격에 수렴했다(같은 사용자가 매일 놀아 준 결과) | 타고난 기질로 되돌아가는 힘(`temperament_pull` 0.025)을 더했다. 성격은 기질과 경험의 중간에 자리 잡는다. 기준값 변화율도 하루 5% → 2.5% |
| 시뮬레이터가 자리 비움 시간의 기분 표본을 적게 세어 하루 평균이 낮 시간에 치우쳤다 | 30분 표본을 30분 몫으로 센다(실제 두뇌의 30초 균등 표본과 맞춤) |

## 한계

- 녹화는 기분 프리셋 6개 × 친밀도 2개에서 가장 가까운 것을 쓴다. 실제 Jev는 수치를 연속으로 반영한다.
