# 웹 프로토타입 수동 확인 체크리스트

웹 화면 조립(`app/src/web/main.ts`)은 브라우저에서 확인한다 ([스펙](../superpowers/specs/2026-10-19-web-prototype-design.md)). 실행: `app/`에서 `npm run build:web`, `brain/`에서 `uv run python -m brain.web`, 브라우저로 `http://127.0.0.1:8787/`.
결과 표기: ✅ 통과 / ❌ 실패 / ⏸ 보류(이유). 확인 날짜를 함께 적는다.

| # | 항목 | 결과 |
|---|---|---|
| W-1 | 페이지를 열면 강아지·집·말풍선 아이콘·톱니바퀴가 보이고, 설정 패널 AI 상태가 "정상"이다 | ✅ 2026-10-19 (chrome-devtools) |
| W-2 | 말풍선 아이콘으로 아래 입력줄이 열리고, 말을 보내면 몇 초 안에 강아지가 말풍선으로 답한다 | ✅ 2026-10-19 ("안녕! 너 이름이 뭐야?" → 2초 뒤 답) |
| W-3 | 강아지를 짧게 누르면 찌르기(놀람·짖기), 끌어서 놓으면 던지기, 누르지 않고 문지르면 쓰다듬기 | 찌르기 ✅ 2026-10-19, 던지기·쓰다듬기 ⏸ 사람이 직접 |
| W-4 | 톱니바퀴 → 로그 탭에 판단(Jev 분포·보정·결과)이 2초마다 갱신된다 | ✅ 2026-10-19 |
| W-5 | 집을 누르면 강아지가 집에 들어가고, 그동안 말을 걸지 않는다. 다시 누르면 나온다 | ⏸ 사람이 직접 |

| W-8 | 두뇌를 껐다 켜면 페이지가 몇 초 안에 다시 붙는다(AI 상태 "두뇌에 연결되지 않음" → "정상") | ⏸ 사람이 직접 |
