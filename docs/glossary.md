# 용어집

| 용어 | 뜻 |
|---|---|
| **Jev** | TypeSafe AI의 System One 모델. 텍스트를 생성하지 않고 구조화된 결정(선택·점수·예/아니오)만 반환한다. [상세](references/typesafe-jev.md) |
| **System One** | TypeSafe가 Jev를 부르는 분류. 빠른 직관적 판단을 하는 모델이라는 뜻이다 |
| **state** | Jev에 넘기는 현재 상황. 이 서비스에서는 타이핑 중인 텍스트, 대화 기록, 캐릭터 상태 등이 들어간다 |
| **question** | Jev에 묻는 질문 하나. 타입은 `choice`, `score`, `noul` 셋 중 하나다 |
| **choice** | 선택지 중 하나를 고르는 질문 타입. 선택지별 확률을 함께 준다 |
| **score** | 순서가 있는 단계(루브릭) 위의 점수를 매기는 질문 타입 |
| **noul** | 문장이 참일 확률을 0~1로 주는 질문 타입 |
| **임계값** | noul 점수를 예/아니오로 바꾸는 기준값. 근거와 함께 기록한다 |
| **실시간 반응** | 사용자가 타이핑을 끝내기 전에 캐릭터가 보이는 감정·액션 |
| **끼어들기** | 사용자가 입력을 끝내기 전에 캐릭터가 말을 시작하는 것 |
| **무응답** | 사용자가 말을 보냈는데 캐릭터가 대사로 답하지 않는 것. Jev가 판단하며, 감정·액션 반응은 할 수 있다 |
| **선발화** | 사용자 입력 없이 캐릭터가 먼저 말을 거는 것 |
| **배경 모드** | 캐릭터가 바탕화면 아이콘 뒤 레이어에 있는 표시 모드. 다른 창에 가려질 수 있다 |
| **오버레이 모드** | 캐릭터가 항상 위에 떠 있는 투명 창에 있는 표시 모드 |
| **가시성** | 지금 사용자가 캐릭터를 볼 수 있는지 여부. Jev 호출 주기를 정하는 데 쓴다 |
| **호출 주기** | Jev에 판단을 요청하는 간격. 가시성과 입력 상태에 따라 달라진다 |
| **두뇌** | 판단(Jev)·대사(Gemini)·대화 기록을 맡는 파이썬 서비스(`brain/`). 화면에 의존하지 않는다 ([0012](decisions/0012-brain-as-frontend-independent-service.md)) |
| **화면** | 두뇌에 접속해 캐릭터를 그리는 프론트엔드. 지금은 Windows(Tauri), 나중에 Android 등. 몸체라고도 한다 |
| **두뇌 핵심** | Signal을 받아 Reaction을 내는 두뇌 코드. 전송 방식을 모른다 |
| **전송 계층** | 화면과 두뇌 핵심을 잇는 부분. 지금은 localhost WebSocket |
| **프로토콜** | 화면과 두뇌가 주고받는 메시지 규약. `docs/brain-protocol.md`가 기준이다 |
| **연속 발화 상한** | 사용자 입력 없이 캐릭터가 연달아 말할 수 있는 최대 횟수 |
| **반응** | 이벤트 하나에 대한 강아지의 즉각적인 정서 반응. 초 단위로 지나간다 (예: 놀람, 반가움, 짜증). 심리학의 emotion |
| **기분** | 여러 일이 쌓여 깔려 있는 강아지의 상태. 분~시간 단위로 변한다 (예: 심심함, 피곤함, 들뜸). 심리학의 mood |
| **이벤트 기록** | 대화를 포함해 강아지에게 일어난 일(찌름, 돌아옴, 집 들어감 등)을 시간순으로 쌓은 것. 두뇌가 저장한다 |
| **친밀도** | 강아지와 사용자의 관계를 나타내는 수치(0~1). 일~주 단위로 천천히 변한다 |
| **성격 파라미터** | 확률 모델의 파라미터로 표현한 성격: 기분마다 기준값·민감도, 변덕, 말수 |
| **기준값** | 아무 일이 없을 때 기분이 돌아가는 값. 평균 회귀 과정의 중심 |
| **민감도** | 같은 일에 기분이 얼마나 크게 움직이는지 |
| **변덕** | 분포에서 뽑을 때 쓰는 온도를 정하는 성격 값. 높을수록 예측하기 어렵다 |
| **말수** | 말할 확률을 로짓 공간에서 밀어 올리거나 내리는 성격 값 |
| **평균 회귀 과정** | 값이 기준값 쪽으로 천천히 돌아가면서 조금씩 무작위로 흔들리는 확률 과정(Ornstein–Uhlenbeck). 시간에 따른 기분 변화에 쓴다 |
| **보정값** | 이벤트 종류마다 말할 확률을 로짓 공간에서 더하거나 빼는 값. v1의 상황별 임계값을 대신한다. 시뮬레이션으로 맞춘다 |
| **Jev 녹화** | 대표 상황에서 받은 실제 Jev 분포를 저장한 것. 시뮬레이터가 Jev 대신 쓴다 |
| **기분 시계** | Jev를 부르지 않고 30초마다 기분을 갱신하는 두뇌의 주기 작업. 움직임 경향이 바뀌면 화면에 보낸다 |
| **움직임 경향** | 두뇌가 성격·기분·친밀도로 계산해 화면에 보내는 평소 움직임 범주(쉬기·잠·돌아다니기·사용자 곁으로·놀기·구경하기)별 가중치와 달리기 비율·머무는 시간 배율 |
| **습관화** | 같은 자극(찌르기·쓰다듬기·던지기)이 반복되면 무뎌지는 정도(0~1). 민감한 성격일수록 천천히 무뎌지고, 시간이 지나면 회복한다 |
| **기질** | 태어날 때의 기준값. 기준값이 경험으로 변해도 아주 약하게 기질 쪽으로 되돌아가 개성이 남는다 |
| **이벤트 묶음** | 판단 중에 온 이벤트를 모아 다음에 한 번에 판단하는 단위 |
| **두드러진 기분** | 기준값보다 0.15 이상 높은 기분 중 가장 높이 오른 것(없으면 평온). 화면이 평소 모습을 고르는 데 쓴다 |
| **듣는 자세** | 타이핑이 시작되면 화면이 두뇌를 기다리지 않고 강아지가 입력창 쪽을 바라보거나 다가오게 하는 즉각 반응 |
| **기분별 시트** | 원본 스프라이트 시트에 기분 하나의 얼굴을 덧그린 시트. manifest의 `moods`에 등록한다 |
| **검수 하네스** | 두뇌를 실제 Jev·Gemini와 가상 시계로 돌려 시나리오를 실행하고 기록·상태 커버리지를 남기는 도구 |
| **검수자** | 비판적인 인간 사용자 페르소나로 하네스 기록을 보고 판정하는 에이전트. 루프마다 새로 띄운다 |
| **랄프 루프** | 같은 프롬프트를 반복해 넣어 검수 → 고침을 검수 통과까지 되풀이하는 방식 |
| **평가 사전값** | 이벤트 하나가 기분에 주는 충격을 우리 모형이 정한 값(예: 던지기 → 무서움). Jev는 종류별 가중치만큼 조정한다 (0015) |
| **습관화 대상** | 자극마다 무뎌지는 기분: 찌르기 → 놀람, 쓰다듬기 → 행복, 던지기 → 무서움, 타이핑 → 궁금함. 다른 기분은 무뎌지지 않는다 |
| **대화 기록** | 대사 프롬프트에 넣는, 실제로 오간 사용자 메시지와 강아지 대사의 최근 20줄. 이벤트 기록(30개 창)과 따로라 하룻밤 뒤에도 남는다 |
| **조용히 부탁** | 사용자가 말 걸지 말라고 한 확률(Jev 질문 hush). 들으면 1시간 동안 먼저 말 걸기가 거의 없다 |
| **달램** | 사용자가 강아지에게 사과하거나 달래는 확률(Jev 질문 soothe). 강아지의 시무룩·무서움·분노를 내리고 공감을 줄인다 |
| **공감** | 사용자가 속상해 보일 확률(Jev 질문 user_down)만큼 강아지가 시무룩해지고 궁금함·기쁨이 꺼지는 우리 모형 규칙 |
| **반대 기분 억제** | 서로 반대인 기분 쌍에서 한쪽이 오르면 다른 쪽이 내리는 규칙 |
