# 동작 선택 = 우리 모형 중심 + Jev 약한 조정 설계

- 날짜: 2026-10-16
- 상태: 구현됨 (검수 루프 결정, [검수 001](../../review/rounds/001.md) 치명 "동작이 사실상 서기 하나")
- 고치는 문서: [두뇌 v2 스펙](2026-10-15-brain-v2-design.md) 6절 동작 점수, [0014](../../decisions/0014-probabilistic-model-with-jev-distributions.md)
- 같은 방향: [0015](../../decisions/0015-appraisal-prior-mood-change.md) (Jev가 잘 못하는 것은 우리 모형이 정한다)

## 1. 문제

검수 001: 판단 168번 중 서기 130·짖기 30, 앉기·엎드리기·잠 0번. 새벽까지 혼자 둬도 서기 27/27. Jev 동작 분포가 서기 0.83~1.00이고, 점수 `log P_Jev / T`의 차이(약 5)가 우리 보정(기분이 0.5에서 벗어난 만큼, ±0.5)보다 열 배 커서 Jev 1위가 그대로 뽑혔다.

## 2. 대안 비교

| 안 | 내용 | 판단 |
|---|---|---|
| A. 보정 가중치만 키움 | `w_mood`·`w_react` 3~5배 | Jev 로그확률 차이가 5 이상이면 여전히 묻힌다. 기분 기준이 0.5라 성격(기준값)이 높은 기분이 늘 보정을 받는다. 기각 |
| B. **우리 모형 중심, Jev는 약하게 (채택)** | 점수 = 기본값 + 이벤트 사전값 + 기분(기준값 대비) + 반응 + α·log(P_Jev + ε). α = 0.3 | Jev가 한쪽으로 쏠려도 최대 영향이 약 0.9로 묶인다. 상황(이벤트)·기분·반응이 동작을 정한다 |
| C. Jev 없이 우리 표만 | | 메시지 내용(예: "앉아!")을 반영하지 못한다. B의 α = 0 |

## 3. 식

```
점수(a) = [ 기본(a) + 이벤트(종류, a) + β·Σ_d 기분표[a][d]·(m_d − μ_d) + γ·반응표[R][a] + α·log(P_Jev(a) + ε) ] / T
α = 0.3, ε = 0.05, β = 5 (기준값보다 0.2 높으면 +1), γ = 1.5, T = 0.5 + 변덕
```

- 기분은 **기준값 대비**로 본다. 늘 졸린 성격이라고 늘 자지 않고, 평소보다 졸릴 때 잔다.
- 이벤트가 여러 개면 이벤트 사전값을 더한다.

| 동작 | 기본 | 기분표 |
|---|---|---|
| 서기 stand | 0.3 | 궁금함 0.5, 놀람 0.3 |
| 앉기 sit | 0.3 | 행복 0.3, 궁금함 0.5, 졸림 0.3 |
| 엎드리기 lie_down | 0.0 | 졸림 0.7, 시무룩 1, 무서움 1 |
| 잠 sleep | −1.5 | 졸림 1.5 |
| 조르기 beg | −0.5 | 행복 1, 들뜸 0.7, 심심함 0.5 |
| 짖기 bark | −0.5 | 분노 1, 놀람 0.8, 들뜸 0.5 |
| 없음 none | 0.3 | |

| 이벤트 | 사전값 |
|---|---|
| poke | 짖기 0.8, 서기 0.3 |
| pet | 조르기 0.8, 앉기 0.8, 엎드리기 0.3 |
| throw | 짖기 0.6, 엎드리기 0.6 |
| quiet | 엎드리기 0.8, 앉기 0.5, 잠 0.3 |
| returned | 조르기 1.0, 짖기 0.5 |
| house_out | 서기 0.5 |
| message, typing | 앉기 0.5, 서기 0.2 (듣는 자세) |
| dog_spoke | 없음 1.2 (방금 말했으면 하던 걸 계속) |

반응표는 기존과 같고 궁금함만 바꿨다(신남·행복 → 조르기, 짜증·놀람 → 짖기, 무서움·서운함·하품 → 엎드리기, 궁금함 → 앉기 0.6·서기 0.4: 귀 기울이는 개는 앉는다). 처음 표(궁금함 → 서기 1)로는 시뮬레이션에서 서기가 63%였다. 고친 뒤 33~40%.

## 3.1 검수 003 개정

- 잠 동작은 졸림이 기준값보다 0.1 넘게 높을 때만(아니면 점수 −10). 잠 기분표에 들뜸 −1, 무서움 −1. 들뜨거나 무서운 강아지가 잠을 고르던 문제.
- 짜증 반응 → 짖기 0.7, 없음 0.5(외면). 화난 강아지가 짖기만 하던 문제.

## 3.2 검수 004 개정

- 하품(졸림) 반응 → 엎드리기 0.6, 잠 0.8. 밤에 잠 동작이 한 번도 안 나오던 문제.

## 4. 시뮬레이션 지표

"Jev 1위 동작 유지 ≥ 0.60"을 없애고 **"가장 흔한 동작 비율 ≤ 0.50"**(한결같음 방지, 검수 001)으로 바꾼다.

## 5. 테스트

- Jev가 서기 0.98을 줘도 쓰다듬기에는 조르기·앉기가 절반 넘게 뽑힌다.
- 평소보다 졸린 강아지가 조용할 때 엎드리기·잠이 절반 넘게 뽑힌다.
- 찌르기에는 짖기가 서기보다 많다.
- 변덕이 크면 분포가 평평해진다. 반응이 동작을 기울인다(기존).
