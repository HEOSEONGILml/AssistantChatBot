# 기분 갱신 수식: 여유 비례·묶음 포화·습관화 대상 분리·신호 반응 설계

## 1. 문제 (검수 002)

| 지적 | 원인 |
|---|---|
| 중요: 기분이 0과 1에 붙는다. 쓰다듬기 한 번에 시무룩·분노·무서움 0 | 변화를 그대로 더하고 0~1로 자른다. 쓰다듬기 사전값(−0.06)에 반대 기분 억제(ρ 0.6 × 행복 상승)가 겹쳐 −0.17이 됐다 |

| 중요: 자기 말 뒤 원인 없는 반응 | 반응 문턱(0.02)이 잡음(σ 0.01) 꼬리와 겹친다. 반응을 잡음이 섞인 변화로 뽑는다 |

| 사소: 세게 던져져도 20분이면 잊음 | 무서움 반감기 5분(평균 3분)이 짧다 |

## 2. 대안 비교

| 안 | 내용 | 판단 |
|---|---|---|
| A. 계수·억제만 줄임 | ρ, 사전값 축소 | 끝에 붙는 문제(덧셈 + 자르기)는 그대로. 연타 합산도 그대로 |
| B. 로짓 공간에서 갱신 | logit m에 더함 | 끝에 붙지 않지만 평균 회귀(OU)와 섞으면 식이 둘이 된다. 테스트·설명이 어렵다 |
| C. **여유 비례 + 묶음 포화 + 대상별 습관화 + 신호 반응 (채택)** | 아래 | 0~1 공간 그대로, 각 결함을 한 줄 규칙으로 막는다 |

## 3. 식

1. **여유 비례**: 오를 때는 남은 여유만큼, 내릴 때는 지금 값만큼 움직인다.
   `m ← m + Δ·(1 − m)` (Δ > 0), `m ← m + Δ·m` (Δ < 0). 끝에 가까울수록 덜 움직여 0·1에 붙지 않는다.
2. **묶음 포화**: 묶음 안 이벤트들의 같은 기분 충격은 확률의 합처럼 합친다.
   오름 `1 − Π(1 − x_i)`, 내림 `−(1 − Π(1 − |x_i|))`. 찌르기 7번(각 0.2)은 1.4가 아니라 0.79다.
3. **대상별 습관화**: 습관화는 그 자극의 대상 기분만 줄인다(찌르기 → 놀람, 쓰다듬기 → **행복**, 던지기 → 무서움). 묶음 안에서도 이벤트마다 습관화를 쌓는다.
   찌르기는 익숙해질수록 짜증이 쌓인다: 분노 `0.06 + 0.15·h`.
4. **경계하는 쓰다듬기**: 쓰다듬기의 행복·들뜸은 지금 분노·무서움이 기준값보다 높은 만큼 줄어든다. `× (1 − min(1, 2·max(0, 분노−기준, 무서움−기준)))`. 화난·무서운 강아지는 여러 번 쓰다듬어야 풀린다. 쓰다듬기의 분노·시무룩·무서움 감소는 −0.06 → −0.03.
5. **억제 ρ** 0.6 → 0.3.
6. **신호 반응**: 반응은 잡음을 뺀 변화(사전값 + Jev)로 뽑고 문턱은 0.03이다. 기분에는 잡음도 더한다. 자기 말에는 신호가 0이라 반응이 없다.
7. **Jev가 실패해도** 사전값만으로 기분·반응·동작을 낸다(대사는 없음). 화면은 이미 반응했고, 0015로 사전값은 우리 모형 몫이다.
8. **무서움 반감기** 5분 → 15분(평균 강아지 9분). 놀람은 금방, 경계는 오래.

## 3.1 거절·무시는 서운함 (검수 002 묶음 3)

- 문제: 욕을 들어도("저리 가 귀찮아") 시무룩이 오히려 내려갔다. 3시간 동안 질문에 답이 없어도 그대로였다. Jev는 거절에 확률 대부분을 친밀도↓(0.53~0.67)에 주고, 우리 모형은 그것을 친밀도에만 반영했다.
- 대안: A Jev 질문 문구를 고쳐 기분으로 답하게 함(녹화·보정 다시, 같은 단일 선택이라 여전히 한 차원에 몰림) / B **관계 해석: 친밀도↓ → 시무룩↑ 0.8배, 친밀도↑ → 행복↑ 0.5배를 우리 모형이 더함 (채택)** / C 메시지 글을 우리가 감정 분석(새 모델·규칙이 필요, 0001의 Jev 역할과 겹침).
- 답을 기다리는 중(물음표 뒤)의 조용함은 시무룩 +0.07/10분(평소 0.01).

## 3.2 타이핑에 익숙해지면 글 내용이 드러난다 (검수 002 묶음 4)

- 문제: 끼어들기 대사가 5번 모두 "무슨 글 써? 궁금해", 타이핑 반응 100% 궁금함. 실측 Jev는 슬픈 글을 쓰는 동안에도 궁금함↑ 0.4~0.56, 시무룩↑ 0.14를 줬다.
- 대안: A 타이핑 궁금함 사전값 제거(첫 타이핑의 궁금함까지 사라짐) / B **타이핑을 습관화 대상(궁금함)에 넣고, Jev 조정의 습관화도 대상 기분에만, 타이핑 Jev 가중치 0.5 → 0.8 (채택)** / C 글 감정 분석을 따로(역할 중복).
- 대사: 끼어들 때 "쓰는 중인 글"을 프롬프트에 따로 넣고, 상황 지시를 "쓰는 중인 글의 내용에 짧게 반응한다. '무슨 글 써?'처럼 모르는 척 묻지 않는다"로 바꿨다.
- 설정 창 상태 탭 습관화에 타이핑 줄을 더했다.

## 3.3 오래 혼자면 심심함 대신 졸음 (검수 002 묶음 5)

- 문제: 낮에 8시간 혼자 두면 심심함 1.00·졸림 0.00으로 종일 돌아다니고 달렸다. 졸린 경향에서도 잠 범주가 1~4%였다.
- 대안: A 조용함의 심심함 사전값만 줄임(짧은 조용함의 심심함까지 사라짐) / B **혼자 있은 시간(마지막 사용자 행동 뒤)에 따라 30분 → 2시간 사이 심심함을 졸림으로 바꿈 + 잠 범주 기본 0.02 → 0.08, 졸림 친화도 1 → 2 (채택)** / C 하루 리듬만 키움(낮에 혼자인 경우를 못 고침).
- 혼자 있은 시간은 두뇌가 기록에서 계산한다(마지막 사용자 이벤트, 최근 500개). 시뮬레이션도 같은 값을 쓴다.

## 3.4 조용함은 우리 몫, 던지기 반복은 무서움, 사과는 서운함을 던다 (검수 003 묶음 1)

- 문제: "다녀올게" 뒤 8시간 조용함 16번이 모두 서운함, 1시간에 시무룩 0.39 → 0.74. 세게 13번 던져도 무서움 반응 0번. 사과가 시무룩을 −0.03만. 키 오류일 때 찔러도 반응 없음.
- 원인: 강아지가 "어디 가?"라고 물으면 답을 기다리는 중이 되어 조용함마다 미답 가산이 쌓였다. 자리를 비운 조용함(30분)도 같게 쳤다. Jev가 조용함마다 시무룩↑·친밀도↓를 줬다. 던지기의 놀람 사전값이 무서움 이상이었고 습관화 대상이 무서움이라 반복할수록 무서움이 더 줄었다.
- 대안: A 미답 가산만 제거(진짜 무시당한 서운함까지 사라짐) / B **자리를 비운 조용함은 서운함 0, 미답 서운함은 한 번만(조용함 판단 뒤 답 기다림 해제), 조용함 Jev 가중치 0.3 → 0.1, 던지기 무서움 0.35·충격·놀람 0.10 + 0.15·충격·습관화 대상 놀람, 친밀도↑ → 시무룩↓ 0.8배, 키 오류도 사전값으로 반응 (채택)** / C 작별 인사를 글에서 알아내 서운함을 끔(글 해석 규칙, 역할 중복).

## 3.5 기분끼리 시간 위에서도 누른다, 경계는 절대 수준 (검수 004 묶음 2)

- 문제: 활발한 강아지가 던져진 뒤 무서움·들뜸이 함께 0.5 이상 5분 30초. 예민한 강아지가 찔린 직후 쓰다듬기에 평균보다 2배 행복(+0.14), 무서움 0.84에 행복 반응. 혼잣말 질문마다 서운함. 연타 뒤 분노 0.93~0.97·궁금함 상승.
- 원인: 반대 기분 억제가 점프 순간에만 있었다(시간 위에서는 들뜸이 높은 기준값으로 금방 돌아감). 경계가 기준값 대비라 기준값이 높은 성마른 강아지는 경계가 거의 0이었다. 답 기다림이 흐름과 상관없이 켜졌다.
- 대안: A 점프 억제 ρ만 키움(쓰다듬기로 나쁜 기분을 지우던 검수 002 결함이 돌아옴) / B **결합 OU: 반대 기분의 기준값 초과분이 돌아갈 자리를 누름(구간 평균으로 간격과 무관, 자리의 1/4 바닥) + 경계는 절대 수준 + 답 기다림은 대화 흐름만 (채택)** / C 반대 기분 쌍을 하나의 축으로 합침(기분 9개 컨셉과 어긋남, 사용자 결정 위반).
- 찌르기: 습관화 분노 +0.15 → +0.10, 궁금함은 익숙할수록 0.
- 시뮬레이션 기분 고착 0.02 → 0.11(목표 ≤ 0.20, 누름이 낮은 기분을 바닥 쪽으로 보냄).

## 4. 테스트

- 쓰다듬기 한 번에 시무룩·분노·무서움이 기준값의 절반 아래로 꺼지지 않는다.
- 기분 1.0 근처에서 같은 자극에 덜 오른다(0·1에 안 붙음).
- 찌르기 7번 묶음의 놀람 상승이 1 미만이고, 습관화가 묶음 안에서 쌓인다.
- 찌르기를 반복하면 놀람 상승은 줄고 분노 상승은 는다. 몇 번째부터 반응이 짜증이 된다.
- 화난 강아지는 첫 쓰다듬기에 행복이 조금만 오른다.
- 자기 말에는 Jev가 뭘 줘도 반응이 없다(잡음 포함).
- Jev 실패 시 찌르기에 놀람 반응과 기분 변화가 남는다.
