## 2. 대안 비교

| 안 | 내용 | 판단 |
|---|---|---|
| A. 계수만 키우고 잡음 줄이기 | Δ = k·(P↑−P↓)에서 k를 키움 | Jev가 틀린 방향(던지기→행복)도 함께 커진다. 자기 말 증폭도 커진다. 기각 |
| B. **평가 사전값 + Jev 조정 (채택)** | 뜻이 정해진 이벤트(몸 상호작용·조용함·돌아옴 등)는 우리 모형이 기분 충격을 정하고, Jev는 이벤트 종류별 가중치만큼 조정한다. 글 내용이 중요한 메시지는 Jev 가중치가 크다 | 0014의 "Jev가 잘 못하는 것은 우리 모형으로 보정"과 맞다. 크기가 사람 감각으로 정해지고 테스트할 수 있다 |
| C. 몸 이벤트는 Jev를 아예 안 씀 | 사전값만 | 같은 찌르기라도 맥락(방금 화났음 등)을 반영하지 못한다. B에서 가중치를 작게 두면 C에 가깝게 된다 |

## 3. 식

이벤트 묶음 E에 대해 기분 d마다:

```
충격_d  = Σ_{e∈E} 사전값(e.kind, e.context)_d               # 우리 평가
조정_d  = change_k · w_jev(마지막 종류) · (P(d↑) − P(d↓))      # Jev
Δ_d    = (충격_d + 조정_d) · 2·민감도_d · (1 − 습관화) + ε,  ε ~ N(0, 0.01)
```

- 민감도 평균이 0.5라 `2·민감도`는 평균 강아지에서 1이다. 사전값은 "평균 강아지가 느끼는 크기"다.
- **억제**: 서로 반대인 기분 쌍(무서움↔행복, 무서움↔들뜸, 분노↔행복, 시무룩↔들뜸, 시무룩↔행복, 졸림↔들뜸)에서 한쪽이 Δ>0만큼 오르면 다른 쪽은 ρ·Δ(ρ = 0.6)만큼 내린다. 사람 감정의 상호 억제(정서의 쌍극 모형)를 단순화했다.
- 친밀도: `intimacy_k · w_jev · (P↑−P↓)` + 사전값(쓰다듬기 +0.005, 던지기 −0.01·충격). `intimacy_k` 0.05 → 0.02(검수 001: 12분에 0.30 → 0.35는 빠름).
- 반응은 그대로 "가장 크게 오른 기분"이다. 자기 말(`dog_spoke`)은 사전값 0, Jev 가중치 0이라 기분이 거의 안 변하고 반응도 거의 안 나온다.

## 4. 사전값 (평균 강아지 기준, 잠정값. 근거: 사람·개 정서 반응의 상식적 크기, 검수 001 기대 동작)

| 이벤트 | 사전값 | Jev 가중치 |
|---|---|---|
| `poke` | 놀람 +0.20, 분노 +0.06, 궁금함 +0.03 | 0.3 |
| `pet` (s = min(초, 5)/3) | 행복 +0.12s, 들뜸 +0.04s, 분노 −0.06s, 시무룩 −0.06s, 무서움 −0.05s | 0.3 |
| `throw` (i = 충격, 없으면 0.5) | 놀람 +0.05+0.25i, 무서움 +0.30i, 분노 +0.05i, 행복 −0.10i, 졸림 −0.10i | 0.3 |
| `quiet` (m = min(초/600, 3)) | 심심함 +0.04m, 시무룩 +0.01m | 0.3 |
| `returned` | 행복 +0.15, 들뜸 +0.12, 심심함 −0.10, 시무룩 −0.08 | 0.3 |
| `house_out` | 들뜸 +0.08, 행복 +0.06 | 0.3 |
| `house_in` | 없음 | 0.3 |
| `typing` | 궁금함 +0.04 | 0.5 |
| `message` | 궁금함 +0.02, 심심함 −0.04 | 1.0 |
| `dog_spoke` | 없음 | 0.0 |

- 시뮬레이션의 말하기 보정값(`kind_bias`)은 말수가 기분에 의존하므로 다시 맞춘다(질문 문구는 그대로라 Jev는 다시 녹화하지 않는다).

## 5. 테스트

- 던지기: Jev가 행복↑를 1위로 줘도 무서움·놀람이 오르고 반응이 놀람 또는 무서움이다.
- 쓰다듬기: 반응이 행복이다.
- 자기 말: Jev가 분노↑를 줘도 기분이 거의 안 변한다.
- 억제: 분노가 오르면 행복이 내린다.
- 조용함: 심심함이 오르고 무서움은 오르지 않는다.
- 돌아옴: 행복·들뜸이 오른다.
- 메시지: Jev 분포가 기분을 움직인다(기존 테스트 유지).
