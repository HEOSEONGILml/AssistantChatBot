# 기분의 시간 감각: 반감기 줄이기 + 하루 리듬 설계

- 날짜: 2026-10-16
- 상태: 구현됨 (검수 루프 결정, [검수 001](../../review/rounds/001.md), 사용자 아는 결함 K-2 "감쇠가 너무 느리다")
- 고치는 문서: [두뇌 v2 스펙](2026-10-15-brain-v2-design.md) 4.2절 평균 회귀

## 1. 문제

- 찔린 짜증이 30분 뒤에도 남았다(예민 강아지 반쯤 회복 26분). 들뜸·궁금함도 15~20분 넘게 갔다.
- 새벽 2시에도 졸림이 기준값(0.3) 그대로였고, 심심하다고 놀자고 졸랐다.

## 2. 대안 비교

| 안 | 내용 | 판단 |
|---|---|---|
| A. 반감기만 줄임 | | 밤 문제를 못 고친다 |
| B. 밤에 졸림 사전값 이벤트를 넣음 | 조용함 이벤트가 졸림을 올림 | 이벤트가 없으면(연결 끊김·집) 안 졸린다. 시간 자체의 효과를 이벤트로 흉내 내는 셈이라 어색하다 |
| C. **반감기 줄이기 + 회귀 목표를 하루 리듬으로 움직임 (채택)** | OU의 평균 μ를 시각의 함수로: μ_d(t) = 기준값_d + a_d·c(t) | 시간 자체가 기분을 움직인다. 하루 평균이 0이라 성격과 하루 평균 기분(성격 변화의 입력)은 그대로다 |

## 3. 식

```
c(h)     = 0.5·cos(2π(h − 3)/24)          새벽 3시 +0.5, 오후 3시 −0.5, 하루 평균 0
μ_d(t)   = clip(기준값_d + a_d·c(시각))     a: 졸림 +0.6, 들뜸 −0.2, 심심함 −0.2
반감기_d = 기본_d × (0.5 + 기준값_d)
```

| 기분 | 기본 반감기 (전 → 후) | 평균 강아지 실제 |
|---|---|---|
| 분노 | 30분 → 10분 | 6분 |
| 놀람 | 3분 → 1분 | 36초 |
| 무서움 | 20분 → 5분 → 15분(검수 002: 던져진 경계는 오래) | 9분 |
| 궁금함 | 15분 → 5분 | 5분 |
| 들뜸 | 20분 → 10분 | 9분 |
| 행복·시무룩·심심함 | 1시간 → 30분 | 21~33분 |
| 졸림 | 2시간 → 1시간 | 48분 |

- 근거: 사람·개의 짧은 정서(놀람·짜증)는 몇 초~몇 분, 기분(행복·심심함)은 몇십 분 단위라는 상식과 검수 001의 기대 동작. 잠정값이다.
- 새벽 3시 평균 강아지: 졸림 자리 0.6, 들뜸 0.3, 심심함 0.5. 졸림이 기준값보다 0.3 높아 두드러진 기분이 하품(sleepy)이 되고, 동작 모형에서 엎드리기·잠 쪽으로 기운다.
- 하루 리듬은 화면 시각이 아니라 두뇌가 받은 시각(로컬 시간)으로 계산한다.

## 4. 테스트

- 찔린 짜증 초과분이 10분 뒤 3분의 1 아래, 놀람은 2분 뒤 0.25 아래.
- 새벽 3시 졸림 > 0.5 > 0.2 > 오후 3시 졸림, 새벽 두드러진 기분은 sleepy, 들뜸은 밤이 낮보다 낮다.
- 리듬 하루 평균 0, 최대는 3시, 최소는 15시.
