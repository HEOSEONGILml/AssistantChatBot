# 연결된 MCP 목록 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설정 탭에 연결된 MCP를 모두(이 프로그램의 파이썬 백엔드 MCP만 빼고) 이름·하는 일·상태로 보여 준다. 백엔드 MCP의 서버 이름을 `assistant`에서 `backend`로 바꾼다.

**Architecture:** 백엔드가 서버별 마지막 상태를 메모리에 둔다. 값은 두 곳에서 온다. (1) 백엔드가 시작할 때 Claude Code를 질문 없이 잠깐 붙여 `get_mcp_status()`로 한 번 읽는다(모델 호출 없음). (2) 세션이 시작될 때마다 오는 `SystemMessage`(`init`)의 `mcp_servers`. 바뀌면 `settings`를 다시 보낸다.

**Tech Stack:** Python 3 (uv, pytest, claude-agent-sdk), Tauri 2 + TypeScript (Vitest)

**Spec:** [스펙](../specs/2026-10-21-assistant-phase1-design.md) 4절 "연결된 MCP", [0030](../../decisions/0030-io-interface-task-as-conversation.md) "수정: 연결된 MCP 목록", [다이제스트](../../design/2026-10-21-output-ui/digest.md) 13번 "연결된 MCP" 칸

## Global Constraints

- 문서와 코드는 같은 커밋. 한국어 문서. Agent SDK API는 Context7(`/websites/code_claude_en_agent-sdk`)로 확인한다.
- 목록은 연결된 MCP 전부다. 이 프로그램의 파이썬 백엔드 MCP만 뺀다 (사용자, 2026-10-22).
- 백엔드 MCP 서버 이름은 `backend`, 도구 접두사는 `mcp__backend__`. 문서에서는 "파이썬 백엔드 MCP"라고 부른다 (사용자: `assistant`는 헷갈린다).
- 프로토콜 v7에 더한다(버전 그대로).

### 정한 값

| 항목 | 값 | 누가 |
|---|---|---|
| 필드 | `settings.mcp_servers: [{name: str, description: str, status: "connected" \| "disconnected" \| "checking"}]` | Claude (0030의 "이름, 하는 일, 상태") |
| 상태 바꾸기 | `connected` → `connected`. `failed`·`needs-auth`·`disabled` → `disconnected`. `pending` → `checking` | 스펙 4절 |
| 순서 | 받은 순서 그대로 | Claude |
| 하는 일 | 설정 모듈(`config.MCP_DESCRIPTIONS`)의 이름별 문구: `screenpipe` `화면 기록 검색`, `claude-in-chrome` `크롬 브라우저 조작`. 그 밖에 이름이 `claude.ai `로 시작하면 `claude.ai 계정 커넥터`, 아니면 빈 글 | 디자인 13번 예시 + Claude |
| 처음 값 | 백엔드 시작 때 읽기 전에는 `screenpipe`, `claude-in-chrome` 두 줄을 `checking`으로. 시작 때 읽기가 실패하면 그대로 두고 실패 종류만 로그 | Claude |
| 실제 확인 값 (2026-10-22) | init `mcp_servers` 항목은 `{name, status, source}`. 예: `screenpipe`·`claude-in-chrome` connected(source `dynamic`), `claude.ai Notion`·`claude.ai Google Drive`·`claude.ai Claude Docs` connected, `claude.ai Gmail`·`Slack`·`Google Calendar`·`Figma` `needs-auth`(source `claudeai`) | 실측 |
| 화면 | 13번 "연결된 MCP" 칸: 제목 `연결된 MCP <개수>`(보이는 줄 수), 줄마다 고정폭 12px/500 이름 + 12px #5B6472 하는 일(말줄임) + 오른쪽 상태. `connected` 초록 점 7px + `연결됨`(#166534), `disconnected` 회색 점(#9AA3AF) + `연결 안 됨`(#5B6472), `checking` 회색 점 + `확인 중` | 디자인 + Claude(나머지 두 상태 색) |
| 설정 탭 스크롤 | 탭 줄 아래 본문 `max-height: 436px; overflow-y: auto` | 디자인 |

## Review Focus

1. **init에 `mcp_servers`가 없거나 모양이 다름**: 무시하고 이전 값을 둔다. → Task 1 `test_init_without_mcp_servers_keeps_list`
2. **백엔드 MCP가 목록에 섞임**: 이름이 `backend`면 뺀다. → Task 1 `test_backend_mcp_excluded`
3. **상태가 그대로면 `settings`를 다시 보내지 않음**. → Task 1 `test_same_status_does_not_resend`
4. **시작 때 읽기가 매달림**: 시간 제한(10초) 뒤 포기하고 프로세스를 끊는다. → Task 1 `test_startup_probe_times_out`
