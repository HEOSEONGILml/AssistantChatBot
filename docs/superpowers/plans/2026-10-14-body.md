# 서브 프로젝트 1: 몸체 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI 없이도 픽셀아트 강아지가 화면 위를 돌아다니고, 강아지 집에 넣고 꺼낼 수 있으며, 클릭·단축키로 입력창을 열고, 말풍선이 뜨고 "봤다" 판정이 되는 Windows 앱을 만든다.

**Architecture:** Tauri 2 앱(`app/`). Rust 셸은 창 설정, 트레이, 키 보관(Windows 자격 증명), 시스템 신호(커서 위치, 마지막 입력, 말풍선 가림)를 맡는다. TypeScript 프론트엔드는 세 창(캐릭터 층, 입력창, 설정)으로 나뉜다. 강아지 이동·스프라이트·말풍선 판정·좌표 변환은 화면과 분리된 순수 모듈로 만들어 Vitest로 테스트한다. 두뇌(서브 프로젝트 2)가 붙을 자리는 `Signal`/`Reaction` 타입과 가짜 두뇌(`StubBrain`)로 비워 둔다.

**Tech Stack:** Tauri 2.12, Rust(stable-msvc, edition 2024), `windows` 0.62, `keyring` 4, TypeScript(vanilla) + Vite, Vitest, `@tauri-apps/plugin-global-shortcut`, `@tauri-apps/plugin-store`

**Spec:** [`docs/superpowers/specs/2026-10-14-windows-desktop-pet-design.md`](../specs/2026-10-14-windows-desktop-pet-design.md) 3·5·6·7절, 결정 기록 [0010](../../decisions/0010-overlay-only-with-doghouse.md)

## Global Constraints

- 표시 방식은 오버레이 하나뿐이다. 배경 모드 코드는 만들지 않는다 (0010).
- 대상은 주 모니터 하나. 첫 버전에 다중 모니터 처리는 넣지 않는다.
- 캐릭터 층과 앱 시작은 포커스를 가져가지 않는다 (스펙 3.2). 입력창만 포커스를 받는다.
- API 키는 Windows 자격 증명 보호(`keyring`)에만 저장한다. 평문 파일·로그에 쓰지 않는다 (0006, 스펙 3.3·6).
- 기본 단축키: 입력창 `Ctrl+Shift+Space`, 강아지 집 `Ctrl+Shift+H`. 설정에서 바꿀 수 있다 (vision).
- 잠정값(말풍선 "봤다" 노출 시간, 판정 후 유지 시간 등)은 코드 상수에 `// 잠정값:` 주석과 근거를 단다 (CLAUDE.md 4절).
- 라이브러리 API는 쓰기 전에 Context7로 확인한다 (CLAUDE.md 5절).
- 코드를 바꾸면 관련 문서를 같은 커밋에서 갱신한다 (CLAUDE.md 1절).
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`를 붙인다.

## Review Focus

1. **화면 배율 125%·150%**: 커서(물리 픽셀)와 강아지 위치(CSS 픽셀) 변환이 틀리면 클릭이 엉뚱한 곳에서 잡힌다 → Task 2에 배율 1.25·1.5 테스트, Task 11 수동 체크에 배율 변경 확인.
2. **작업 표시줄 위치·크기**: 바닥선은 작업 영역(workArea) 기준이어야 한다. 작업 표시줄이 왼쪽·위에 있거나 자동 숨김일 때도 강아지가 화면 밖으로 나가지 않아야 한다 → Task 4 테스트(바닥 폭 경계), Task 11 수동 체크.
3. **집에 들어가는 도중 클릭**: 강아지가 집으로 걸어가는 중에 다시 집을 누르면 바로 돌아 나와야 한다 → Task 4 테스트.
4. **키가 없는 첫 실행**: 키가 없으면 돌아다니기만 하고 안내 말풍선을 띄운다. 키 저장 실패(자격 증명 저장소 오류)도 설정 창에 오류로 보여야 한다 → Task 10 테스트·수동 체크.
5. **단축키 충돌**: 다른 앱이 이미 쓰는 단축키로 바꾸면 등록이 실패한다. 이전 단축키로 되돌리고 설정 창에 알려야 한다 → Task 10 구현과 수동 체크.

```ts
export type Point = { x: number; y: number };
export type Box = { left: number; top: number; width: number; height: number };

export function physToCss(p: Point, windowOrigin: Point, scale: number): Point {
  return { x: (p.x - windowOrigin.x) / scale, y: (p.y - windowOrigin.y) / scale };
}

export function cssBoxToPhys(b: Box, windowOrigin: Point, scale: number) {
  return {
    left: Math.round(windowOrigin.x + b.left * scale),
    top: Math.round(windowOrigin.y + b.top * scale),
    right: Math.round(windowOrigin.x + (b.left + b.width) * scale),
    bottom: Math.round(windowOrigin.y + (b.top + b.height) * scale),
  };
}

export function boxContains(b: Box, p: Point): boolean {
  return p.x >= b.left && p.x < b.left + b.width && p.y >= b.top && p.y < b.top + b.height;
}
```

`app/src/body/sprite.ts`:

```ts
export type Animation = { row: number; frames: number; fps: number; loop: boolean };
export type Manifest = {
  image: string; frameWidth: number; frameHeight: number; scale: number;
  animations: Record<string, Animation>;
};

export const DOG_ACTIONS = ["walk", "run", "idle_stand", "idle_sit", "idle_lay", "sleep", "beg", "bark"] as const;
export type DogAction = (typeof DOG_ACTIONS)[number];

export function frameAt(m: Manifest, anim: string, elapsedMs: number) {
  const a = m.animations[anim] ?? m.animations["walk"];
  const raw = Math.floor((elapsedMs / 1000) * a.fps);
  const i = a.loop ? raw % a.frames : Math.min(raw, a.frames - 1);
  return { sx: i * m.frameWidth, sy: a.row * m.frameHeight, sw: m.frameWidth, sh: m.frameHeight };
}
```

```ts
import type { DogAction } from "./sprite";

export type DogMode = "wander" | "action" | "to_house" | "in_house" | "from_house";
export type Dog = { x: number; dir: 1 | -1; mode: DogMode; action: DogAction; actionEnd: number; houseSince: number | null };
export type World = { floorWidth: number; dogWidth: number; houseX: number; speed: number };

const EXIT_DISTANCE = 80; // 집에서 나와 걷는 거리(CSS px)

export function newDog(x: number): Dog {
  return { x, dir: 1, mode: "wander", action: "walk", actionEnd: 0, houseSince: null };
}

function walkToward(d: Dog, target: number, w: World, dtMs: number): Dog {
  const stepPx = (w.speed * dtMs) / 1000;
  const dir: 1 | -1 = target >= d.x ? 1 : -1;
  const x = Math.abs(target - d.x) <= stepPx ? target : d.x + dir * stepPx;
  return { ...d, x, dir };
}

export function step(d: Dog, w: World, now: number, dtMs: number): Dog {
  switch (d.mode) {
    case "wander": {
      const max = w.floorWidth - w.dogWidth;
      let x = d.x + (d.dir * w.speed * dtMs) / 1000;
      let dir = d.dir;
      if (x >= max) { x = max; dir = -1; }
      if (x <= 0) { x = 0; dir = 1; }
      return { ...d, x, dir };
    }
    case "action":
      return now >= d.actionEnd ? { ...d, mode: "wander" } : d;
    case "to_house": {
      const n = walkToward(d, w.houseX, w, dtMs);
      return n.x === w.houseX ? { ...n, mode: "in_house", houseSince: now } : n;
    }
    case "in_house":
      return d;
    case "from_house": {
      const target = w.houseX - EXIT_DISTANCE;
      const n = walkToward(d, target, w, dtMs);
      return n.x === target ? { ...n, mode: "wander", dir: -1 } : n;
    }
  }
}

export function playAction(d: Dog, a: DogAction, now: number, durationMs: number): Dog {
  if (d.mode === "to_house" || d.mode === "in_house" || d.mode === "from_house") return d;
  return { ...d, mode: "action", action: a, actionEnd: now + durationMs };
}

export function toggleHouse(d: Dog, _now: number): Dog {
  switch (d.mode) {
    case "wander":
    case "action":
    case "from_house":
      return { ...d, mode: "to_house" };
    case "to_house":
      return { ...d, mode: "wander" };
    case "in_house":
      return { ...d, mode: "from_house", houseSince: null };
  }
}

export function currentAnimation(d: Dog): DogAction {
  if (d.mode === "action") return d.action;
  if (d.mode === "in_house") return "sleep";
  return "walk";
}
```

```ts
// 잠정값: 한 문장을 읽는 데 2~3초. 평가 단계(서브 프로젝트 3)에서 다시 정한다.
export const SEEN_MS = 3000;
// 잠정값: 뒤늦게 볼 수 있도록 길게(vision "한참 더 남는다"). 10분.
export const KEEP_AFTER_SEEN_MS = 10 * 60 * 1000;

export type Bubble = { text: string; visibleMs: number; seenAt: number | null } | null;

export function showBubble(text: string): Bubble {
  return { text, visibleMs: 0, seenAt: null };
}

export function tickBubble(b: Bubble, now: number, dtMs: number, unobstructed: boolean): { bubble: Bubble; justSeen: boolean } {
  if (!b) return { bubble: null, justSeen: false };
  if (b.seenAt !== null) {
    return { bubble: now - b.seenAt >= KEEP_AFTER_SEEN_MS ? null : b, justSeen: false };
  }
  const visibleMs = unobstructed ? b.visibleMs + dtMs : b.visibleMs;
  if (visibleMs >= SEEN_MS) return { bubble: { ...b, visibleMs, seenAt: now }, justSeen: true };
  return { bubble: { ...b, visibleMs }, justSeen: false };
}
```

```rust
use crate::geom::Rect;
use windows::Win32::Foundation::{HWND, POINT, RECT};
use windows::Win32::Graphics::Dwm::{DwmGetWindowAttribute, DWMWA_CLOAKED, DWMWA_EXTENDED_FRAME_BOUNDS};
use windows::Win32::System::SystemInformation::GetTickCount;
use windows::Win32::UI::Input::KeyboardAndMouse::{GetLastInputInfo, LASTINPUTINFO};
use windows::Win32::UI::WindowsAndMessaging::{GetCursorPos, GetWindow, IsIconic, IsWindowVisible, GW_HWNDPREV};

pub fn windows_above(own: HWND) -> Vec<Rect> {
    let mut out = Vec::new();
    unsafe {
        let mut h = GetWindow(own, GW_HWNDPREV);
        while let Ok(w) = h {
            if w.is_invalid() { break; }
            let mut cloaked = 0u32;
            let _ = DwmGetWindowAttribute(w, DWMWA_CLOAKED, &mut cloaked as *mut _ as _, 4);
            if IsWindowVisible(w).as_bool() && !IsIconic(w).as_bool() && cloaked == 0 {
                let mut r = RECT::default();
                if DwmGetWindowAttribute(w, DWMWA_EXTENDED_FRAME_BOUNDS, &mut r as *mut _ as _, std::mem::size_of::<RECT>() as u32).is_ok() {
                    out.push(Rect { left: r.left, top: r.top, right: r.right, bottom: r.bottom });
                }
            }
            h = GetWindow(w, GW_HWNDPREV);
        }
    }
    out
}

pub fn cursor() -> (i32, i32) {
    let mut p = POINT::default();
    unsafe { let _ = GetCursorPos(&mut p); }
    (p.x, p.y)
}

pub fn idle_ms() -> u32 {
    unsafe {
        let mut li = LASTINPUTINFO { cbSize: std::mem::size_of::<LASTINPUTINFO>() as u32, dwTime: 0 };
        let _ = GetLastInputInfo(&mut li);
        GetTickCount().wrapping_sub(li.dwTime)
    }
}
```

```ts
async function main() {

  const sheet = new Image();

  sheet.onload = () => (sheetOk = true);

  const origin = await win.outerPosition();

  const dogH = manifest.frameHeight * manifest.scale;
  const houseW = HOUSE_PX.width * HOUSE_SCALE;
  const houseH = HOUSE_PX.height * HOUSE_SCALE;

  const houseBox: Box = { left: world.houseX, top: workBottom - houseH, width: houseW, height: houseH };

  let bubble: Bubble = null;
  let hideHouseWhenInside = false; // Task 10에서 설정과 연결
  let last = performance.now();
  let animStart = last;

  const doToggleHouse = () => {
    const before = dog.mode;
    dog = toggleHouse(dog, Date.now());
    if (before === "in_house") emit("signal", { kind: "house", inside: false, awayMs: Date.now() - (dogHouseSince ?? Date.now()) });
    if (dog.mode === "to_house") { bubble = null; bubbleEl.hidden = true; }
  };
  let dogHouseSince: number | null = null;

  listen<Reaction>("reaction", (e) => {
    if (dog.mode === "in_house" || dog.mode === "to_house") return; // 집에서는 완전히 조용 (vision)
    if (e.payload.action) dog = playAction(dog, e.payload.action, Date.now(), ACTION_MS);
    if (e.payload.utterance) { bubble = showBubble(e.payload.utterance); bubbleEl.textContent = e.payload.utterance; }
  });
  listen("toggle-house", doToggleHouse);
  listen<boolean>("setting-hide-house", (e) => (hideHouseWhenInside = e.payload));

    const overDog = dog.mode !== "in_house" && boxContains(dogBox(), p);
    const overHouse = !(hideHouseWhenInside && dog.mode === "in_house") && boxContains(houseBox, p);
    const over = overDog || overHouse;

      const b = cssBoxToPhys(dogBox(), origin, scale);
      emit("open-input", { x: b.left, y: b.top });

  });

      else { ctx.fillStyle = "#c8843a"; ctx.fillRect(b.left, b.top, dogW, dogH); }
      ctx.restore();

    bubble = t.bubble;
    if (t.justSeen) emit("signal", { kind: "bubble_seen" });

    if (bubble) {
      const b = dogBox();
      bubbleEl.style.left = `${Math.min(b.left, window.innerWidth - 280)}px`;
      bubbleEl.style.top = `${b.top - bubbleEl.offsetHeight - 8}px`;
    }
    requestAnimationFrame(frame);
  };
  requestAnimationFrame(frame);
}
```

```ts
import { Store } from "@tauri-apps/plugin-store";

export type Settings = { inputAlwaysVisible: boolean; hideHouseWhenInside: boolean; inputShortcut: string; houseShortcut: string };

export const DEFAULT_SETTINGS: Settings = {
  inputAlwaysVisible: false,
  hideHouseWhenInside: false,
  inputShortcut: "CommandOrControl+Shift+Space",
  houseShortcut: "CommandOrControl+Shift+H",

export function withDefaults(partial: Partial<Settings> | null | undefined): Settings {
  return { ...DEFAULT_SETTINGS, ...(partial ?? {}) };

export async function loadSettings(): Promise<Settings> {
  const store = await Store.load("settings.json");

}

export async function saveSettings(s: Settings): Promise<void> {
  const store = await Store.load("settings.json");
  await store.set("settings", s);
  await store.save();
}
```

```rust
const SERVICE: &str = "TamagotchiChatBot";
const ALLOWED: [&str; 2] = ["typesafe", "gemini"];

fn entry(name: &str) -> Result<keyring::Entry, String> {
    if !ALLOWED.contains(&name) { return Err(format!("unknown key name: {name}")); }
    keyring::Entry::new(SERVICE, name).map_err(|e| e.to_string())
}

pub fn set(name: &str, value: &str) -> Result<(), String> {
    if value.trim().is_empty() { return Err("빈 키는 저장하지 않습니다".into()); }
    entry(name)?.set_password(value.trim()).map_err(|e| e.to_string())
}

pub fn has(name: &str) -> Result<bool, String> {
    match entry(name)?.get_password() {
        Ok(_) => Ok(true),
        Err(keyring::Error::NoEntry) => Ok(false),
        Err(e) => Err(e.to_string()),
    }
}

pub fn delete(name: &str) -> Result<(), String> {
    match entry(name)?.delete_credential() {
        Ok(()) | Err(keyring::Error::NoEntry) => Ok(()),
        Err(e) => Err(e.to_string()),
    }
}
```

`app/src/settings-page.ts`:

```ts
import { invoke } from "@tauri-apps/api/core";
import { emit, listen } from "@tauri-apps/api/event";
import { loadSettings, saveSettings, type Settings } from "./shared/settings";

const $ = <T extends HTMLElement>(id: string) => document.getElementById(id) as T;
const msg = $("msg");
const KEYS = ["typesafe", "gemini"] as const;

async function refreshKeyState() {
  for (const k of KEYS) {
    try { $(`${k}-state`).textContent = (await invoke<boolean>("key_has", { name: k })) ? "(저장됨)" : "(없음)"; }
    catch (e) { $(`${k}-state`).textContent = `(확인 실패: ${e})`; }
  }
}

async function init() {
  const s = await loadSettings();
  ($("inputAlwaysVisible") as HTMLInputElement).checked = s.inputAlwaysVisible;
  ($("hideHouseWhenInside") as HTMLInputElement).checked = s.hideHouseWhenInside;
  ($("inputShortcut") as HTMLInputElement).value = s.inputShortcut;
  ($("houseShortcut") as HTMLInputElement).value = s.houseShortcut;
  await refreshKeyState();
}

$("save").addEventListener("click", async () => {
  msg.textContent = "";
  const s: Settings = {
    inputAlwaysVisible: ($("inputAlwaysVisible") as HTMLInputElement).checked,
    hideHouseWhenInside: ($("hideHouseWhenInside") as HTMLInputElement).checked,
    inputShortcut: ($("inputShortcut") as HTMLInputElement).value.trim(),
    houseShortcut: ($("houseShortcut") as HTMLInputElement).value.trim(),
  };
  try {
    for (const k of KEYS) {
      const v = ($(k) as HTMLInputElement).value;
      if (v.trim()) { await invoke("key_set", { name: k, value: v }); ($(k) as HTMLInputElement).value = ""; }
    }
    await saveSettings(s);
    await emit("settings-changed", s);
    msg.textContent = "저장했습니다.";
  } catch (e) {
    msg.textContent = `저장 실패: ${e}`;
  }
  await refreshKeyState();
});

document.querySelectorAll<HTMLButtonElement>("[data-del]").forEach((b) =>
  b.addEventListener("click", async () => {
    try { await invoke("key_delete", { name: b.dataset.del }); msg.textContent = "키를 삭제했습니다."; }
    catch (e) { msg.textContent = `삭제 실패: ${e}`; }
    await refreshKeyState();
  }),
);

listen<string>("shortcut-error", (e) => (msg.textContent = e.payload));
init();
```

4. 키 삭제 버튼이 동작한다.

6. 단축키를 `Ctrl+Alt+K`로 바꾸고 저장하면 새 단축키가 바로 동작하고 이전 것은 동작하지 않는다.

8. "집 숨기기"를 켜고 강아지를 집에 넣으면 집도 사라진다. 트레이·단축키로 다시 꺼낼 수 있다.
9. 설정 창 닫기 버튼은 창을 숨기기만 한다(트레이에서 다시 열 수 있다).
