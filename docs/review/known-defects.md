# 아는 결함 (검수자 보정용)

사용자가 직접 든 결함이다. 검수자가 이것을 못 찾으면 고치기 전에 [`reviewer.md`](reviewer.md)를 고친다(스펙 4절 "검수자 보정"). 루프는 이 파일을 검수자에게 보여 주지 않는다. 판정 파일과 비교만 한다.

| # | 결함 | 출처 |
|---|---|---|
| K-1 | 서로 반대인 기분(예: 무서움과 행복)이 동시에 높다. 부적절하다 | 사용자, 2026-10-15 |
| K-2 | 기분의 감쇠 속도가 사람이 느끼기에 너무 느리다 | 사용자, 2026-10-15 |
| K-3 | 반응·동작이 너무 한결같다. 뭘 해도 짖기가 거의 고정으로 나온다 | 사용자, 2026-10-15 |
| K-4 | 반응이 자극과 맞지 않는다. 놀라야 하는데 들뜬다 | 사용자, 2026-10-15 |
| K-5 | 기분에 따라 행동이 다른 것이 체감되지 않는다. 들뜨면 마구 달리고, 졸리면 주로 엎드려야 한다 | 사용자, 2026-10-15 |

사용자가 써 보며 더 알려 주면 여기에 추가한다.
