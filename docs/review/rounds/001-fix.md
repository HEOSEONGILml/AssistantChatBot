# 검수 001 고치기

## 묶음 1: 기분 변화 모형 (2026-10-16)

**고친 지적**
- [치명] 반응이 자극과 맞지 않는다 → 고침
- [치명] 자기 말로 자기 기분을 키워 1.00에 붙는다 → 고침
- [중요] 기분 변화가 이벤트 크기와 맞지 않는다 → 고침(친밀도 속도 포함)
- [중요] 반대 기분이 함께 높다 → 고침(억제)
- [중요] 혼자 두면 무서워하고 돌아오면 놀란다 → 고침(조용함 → 심심함, 돌아옴 → 행복·들뜸)
- [사소] 평범한 타이핑에 놀람 → 고침(잡음 0.02 → 0.01, 타이핑 → 궁금함)

**원인**: 기분 변화가 Jev 변화 분포에서만 왔다. 21개 선택지에 확률이 퍼져 신호(0.03~0.04)가 잡음(0.02)과 같은 크기였고, Jev도 던지기에 행복↑를 1위로 줬다. 자기 말(`dog_spoke`)도 같은 크기로 기분을 바꿔 되먹임이 생겼다. 기분끼리 상호작용이 없었다.

**설계 점검 (대안 비교)**

| 안 | 수학·통계 | 사람 감각 | 단순성 | 테스트 | 판단 |
|---|---|---|---|---|---|
| A. 계수만 키움 | 신호대잡음비는 오르나 Jev의 틀린 방향도 커짐 | 던지기 → 행복이 더 커짐 | 가장 단순 | 쉬움 | 기각 |
| B. 평가 사전값 + Jev 가중 조정 + 반대 기분 억제 | 사전값이 조건부 기댓값 역할, Jev는 맥락 잔차. 억제는 쌍극 정서 모형의 단순화 | 자극 → 반응이 맞고 크기를 사람이 정함 | 표 하나 + 가중치 | 사전값 방향을 직접 검사 | **채택** |
| C. 몸 이벤트는 Jev 없이 | 맥락 정보 버림 | 같은 찌르기에 늘 같은 반응 | 단순 | 쉬움 | B의 특수한 경우(가중치 0)로 남김 |

**적용**: [스펙](../../superpowers/specs/2026-10-16-appraisal-prior-design.md), [0015](../../decisions/0015-appraisal-prior-mood-change.md). 말하기 보정값 다시 맞춤(시뮬레이션 문서).

## 묶음 2: 동작 선택 모형 (2026-10-16)

**고친 지적**: [치명] 동작이 사실상 '서기' 하나다 → 고침

**원인**: 동작 점수에서 Jev 로그확률 차이(서기 0.98 → 약 5)가 우리 보정(±0.5)보다 열 배 컸다. 기분 보정의 기준이 0.5라 성격도 섞였다.

**설계 점검**: A 보정 가중치만 키움(쏠림이 크면 여전히 묻힘, 기각) / B 우리 모형 중심 + Jev 로그확률을 0.3배·바닥 0.05로 묶음(**채택**) / C Jev 없이(메시지 내용 반영 불가, B의 α=0). 처음 표로는 시뮬레이션 서기 63%라 궁금함 → 앉기 쪽으로, 자기 말 → 없음 쪽으로 다시 맞춰 33~40%. [스펙](../../superpowers/specs/2026-10-16-action-model-design.md), [0016](../../decisions/0016-action-model-ours-first.md).

## 묶음 3: 시간 감각 (2026-10-16)

**고친 지적**: [중요] 찌르기 짜증이 30분 넘게 간다, [중요] 밤에 졸리지 않는다 → 고침 (사용자 K-2)

**원인**: 반감기가 사람 감각보다 3~5배 길었다. 회귀 목표(기준값)가 하루 내내 같아 밤이 낮과 같았다.

**설계 점검**: A 반감기만(밤 문제 남음) / B 밤 졸림 이벤트(이벤트 없으면 안 졸림, 기각) / C 반감기 줄이기 + OU 평균을 하루 리듬 함수로(**채택**, 하루 평균 0이라 성격 변화 입력 불변). [스펙](../../superpowers/specs/2026-10-16-time-model-design.md).

## 묶음 4: 기분별 움직임 (2026-10-16)

**고친 지적**: [중요] 기분에 따라 움직임이 달라지는 것이 체감되지 않는다 → 고침 (사용자 K-5)

**원인**: 움직임 경향이 기분을 0.5 기준으로, 1배로 봤다. 기분이 평소보다 0.3 올라도 경향이 1.3배뿐이었고, 기준값이 높은 성격은 늘 같은 쪽으로 기울었다.

**설계 점검**: A 계수만 키움(0.5 기준이라 성격 효과도 함께 커짐, 기각) / B 기분은 기준값 대비 ×4, 성격은 기준값 ×1로 분리(**채택**) / C 화면이 두드러진 기분별로 고정 프로필을 고름(두뇌의 연속 분포를 버림, 기각). 부작용으로 전송이 시간당 95번이 되어, 문턱 0.30·흔들림 σ 0.03으로 약 12번. 말하기 보정값 다시 맞춤.

## 묶음 5: 대사 지시 (2026-10-16)

**고친 지적**: [중요] 같은 대사 반복, [중요] 던지기를 '날아왔다'로 이해, [중요] 질문에 안 답함·위로 뒤집기, [사소] "멍" 시작 일색, [사소] 이유 없는 사과 → 고침

**원인**: Gemini가 이벤트 이름(던지기·찌르기)만 받고 뜻을 몰랐다. 자기가 최근에 한 말과 지금 말하는 상황(답하기·이어 말하기)을 따로 받지 않았다. 대화 규칙이 없었다.

**설계 점검**: A Jev 상태의 이벤트 이름 자체를 바꿈(Jev 분포가 바뀌어 녹화·보정을 다시 해야 함, 비용 큼) / B Gemini 지시에만 이벤트 뜻·대화 규칙, 프롬프트에 상황·최근 한 말(**채택**, Jev 녹화 유지) / C 같은 말이 나오면 걸러 다시 생성(호출이 늘고 근본 원인 그대로, 기각). 실제 호출 확인: "너라면 뭐 골라?"에 "나는 당연히 짜장면!", 위로 요청에 "내가 옆에 있을게" → "꼬리로 토닥토닥해 줄게"로 이어짐.
