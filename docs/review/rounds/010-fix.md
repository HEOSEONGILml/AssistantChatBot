# 검수 010 고치기

## 묶음 1: 명령을 따르고, 말한 동작이 실제 동작 (2026-10-16)

**고친 지적**: [중요] 명령을 따르지 않고, 말과 동작이 어긋난다 → 고침

**원인**: 동작 모형(0016)이 Jev 동작 로그확률을 0.3배로만 반영해, 글 내용이 동작을 정하는 명령에도 우리 사전값(메시지 → 앉기·서기)이 앞섰다. 대사 지시에 "말로 한 동작 = 뽑힌 동작" 규칙이 없었다.

**설계 점검**: A 명령 낱말 표(글 해석은 Jev 몫) / B 메시지에서는 Jev 동작 무게 1.5, 몸 이벤트는 0.3 그대로 + 대사 규칙(**채택**, 0015의 기분 변화 가중치와 같은 원리) / C 동작 질문을 명령용으로 따로(질문 늘고 다시 녹화).

## 묶음 2: 사과에는 대답 (2026-10-16)

**고친 지적**: [중요] 사과에는 절반 넘게 아무 말도 없다 → 고침. 함께: "사용자" 낱말이 대사에 새던 것(중요 4의 일부)은 다듬기에서 "너"로 바꾼다.

**원인**: 대답 보정(+3.5)이 질문·부탁·속상한 이야기에만 있고 사과에는 없었다. **설계 점검**: A 메시지 보정값 전체를 올림(평범한 말도 다 대답) / B 달램 ≥ 0.5인 메시지를 대답 보정에 넣음(**채택**, 두뇌·시뮬레이션 같은 규칙) / C 사과엔 반드시 대답(확률 모형 밖). 겁먹은 강아지는 여전히 입을 다문다(무서움 억제가 같이 걸림).

## 묶음 3: 지시 속 예시 문장 걷기 (2026-10-16)

**고친 지적**: [중요] 같은 틀(집 = 좁고 답답, 위로 = 옆에 있을게, 간식), [중요] 쉬운 질문을 흘리거나 엇나감·역할 혼동 → 고침(일부 남음)

**원인**: 대사 지시 안의 예시 문장이 그대로 틀이 됐다. 집에서 나옴 지시에 "'나 나왔다! 집 안 답답했어'처럼", 위로 규칙에 "('내가 옆에 있을게')"가 있었다(검수 004·005에서 내가 넣은 예시). 먹을 것으로 돌리기·쉬운 질문·생일 주인에 대한 원칙이 없었다.

**설계 점검**: A 금지 목록에 그 표현을 더함(예시가 계속 끌어당김) / B 예시 대사를 지우고 원칙만(집은 쉬는 곳, 위로는 매번 다른 방식, 먹을 것으로 돌리지 않음, 자신에 대한 쉬운 질문엔 구체적으로, 생일·이름·일정은 사용자 것)(**채택**) / C 대사 여러 개 중 고르기(호출 늘어남). 실제 호출: 집에서 나온 뒤 "포근하고 좋았어", "밖으로 나오니 공기가 좋네", "폭신한 침대에서 뒹굴거리며"(예민만 "답답")·"너는 뭐 좋아해?"에 "따뜻한 햇볕 아래 엎드려 있는 시간". 위로의 "옆에 (앉아) 있을게"는 여전히 자주 나오고, "너라면 어떻게 했을 것 같아?"에 "왈."이 한 번 나왔다.
