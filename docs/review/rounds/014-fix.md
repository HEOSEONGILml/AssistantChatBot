# 검수 014 고치기

## 묶음 1: 대답 다듬기의 역효과 (2026-10-19)

**고친 지적**: [중요] 직접 물었는데 침묵한다(말하기 0.99~1.0, Gemini가 "멍!"만 줘서 버림), [중요] 대사가 "!"로 시작한다 → 고침

**원인**:
- 침묵: 검수 013 묶음 3이 "메시지에 의성어뿐인 대답은 말하지 않는다"를 넣었다. Gemini가 가끔 "멍!"만 주는데(6번), 그때 대답이 통째로 사라졌다. 이 루프가 만든 역효과다.
- "!": `_STOCK_OPENING`이 "드디어"와 쉼표만 걷어 "드디어! 신나게…"가 "! 신나게…"가 됐다.

**설계 점검**:
- 침묵: A 의성어뿐이어도 내보냄(검수 013 지적이 되살아남) / B **한 번 다시 묻는다(이유를 덧붙여) (채택)**: 드물어(6/400 남짓) 호출이 거의 늘지 않고, 대답하기로 뽑힌 결정을 지킨다 / C 대사 지시 규칙 추가(효과가 작았다).
- "!": 걷는 패턴이 뒤따르는 문장부호까지 먹고, 다듬은 글의 앞 문장부호를 지운다.

**바꾼 것**:
- 두뇌: 메시지 대답이 의성어뿐이면(짖으라고 시킨 때 빼고) 프롬프트에 "의성어만 쓰지 말고, 주인 말에 내용이 있는 말로 답한다."를 붙여 한 번 다시 묻는다. 판단 로그에 `utterance_retry`. 그래도 의성어뿐이면 전처럼 버린다.
- `_STOCK_OPENING` = `드디어\s*[,!~.]*\s*`, 다듬은 글은 앞의 `!?,.~…`를 지운다.

**확인**:
- 테스트 2개 추가(다시 묻기, 문장부호 찌꺼기). 두뇌 테스트 279개 통과.
- 실제 호출(probe-r14-ask-support·probe-scolded-all·probe-where-are-you·probe-r14-play-stub, Jev 약 150·Gemini 약 60): 말할 확률 0.9 이상인 메시지 53개 중 52개에 내용 있는 대답(남은 하나는 0.911 동전이 침묵으로 나옴). "!"로 시작하는 대사 0. 이번에는 의성어뿐인 대답이 나오지 않아 다시 묻기는 일어나지 않았다(단위 테스트로 확인).

## 묶음 2: 잠자리 ("잘 자" 뒤에는 잔다) (2026-10-19)

**고친 지적**: [중요] 새벽에 "잘 자"라고 한 뒤에도 강아지가 잠들지 않고 심심해·서운해하며 말을 건다 → 고침

**원인** (`probe-r14-night-sleep` 판단 로그):
- Jev는 "이제 자자 잘 자"를 시킨 잠 0.92~0.96으로 읽었다(검수 011 질문). 그 순간 동작(엎드리기)에만 쓰고, 그 뒤 상태에는 남기지 않았다.
- 그 뒤 조용함(자리에 있음, 10분)은 낮과 같이 읽혔다. 주인이 곁에 있으면 '혼자 시간'이 짧아 심심함이 오르고, 강아지가 직전에 물었으면(`_waiting`) 서운함이 올랐다. 먼저 말 걸기도 낮과 같았다.

**설계 점검**:
- A. Jev에 "잘 자" 질문을 더한다. 시킨 잠으로 이미 깨끗하게 읽혀(0.79~0.96) 필요 없고, 다시 녹화가 든다.
- B. 하루 리듬(새벽 졸림)을 키운다. "잘 자"와 상관없이 밤이 다 졸려지고, 말하지 않은 새벽에도 같다.
- C. 시킨 잠을 **잠자리 상태**로 남긴다(**채택**). "말 걸지 마"(hush)와 같은 꼴(시간 + 사용자가 말하면 끝)이고, 조용함은 이미 있는 "오래 혼자면 졸음"(검수 002) 규칙으로 읽는다. 새 수식이 없다.

**바꾼 것**:
- 두뇌: 메시지 판단에서 시킨 잠 ≥ 0.5면 `_bed_until` = 지금 + `bed_s`(8시간). 사용자 메시지가 오면 끝. 잠자리 동안 `_hush_until`도 같이(먼저 말 걸기 −5), 답 기다림 서운함 끔, 조용함의 혼자 시간은 최소 `bed_alone_s`(2시간).
- 시뮬레이션은 녹화 메시지가 "오늘 점심 뭐 먹지"뿐이라 바뀌지 않는다.

**확인**:
- 테스트 1개 추가(잠자리 뒤 조용함 세 번: 지루함·서운함 없음, 말할 확률 < 0.05, 졸림 +0.1 넘게). 두뇌 테스트 280개 통과.
- 실제 호출(probe-r14-night-sleep·probe-night-return, Jev 약 60·Gemini 약 10): 네 성격 모두 "잘 자" 뒤 10분마다 하품, 두세 번째부터 잠 동작. 졸림 0.37~0.39 → 30분 뒤 0.55~0.65. 말할 확률 0.001~0.009, 말 0번(전에는 지루함·서운함, 두 마리가 새벽 2시 반에 말을 걺). "잘 자"에 대한 대답은 "하아암, 졸려... 내일도 같이 놀자. 멍."
