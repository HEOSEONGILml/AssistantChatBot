# 검수 009 고치기

## 묶음 1: 대사(되풀이 틀, 화면 밖 장소) (2026-10-16)

**고친 지적**: [중요] 상황마다 같은 틀(위로 "옆에 있을게", 반김 "목 빠지는 줄 알았어"), [중요] 바탕화면 강아지가 화면 밖 장소·물건에 있다고 지어냄 → 고침(위로의 "곁에/여기 있을게" 계열은 줄었지만 남음)

**원인**: 틀 금지와 장소 규칙을 지시 문구로만 줬고, LLM은 되풀이를 스스로 세지 못한다.

**설계 점검**: A 규칙 문구만 더(검수 003~008에서 반복, 효과 작음) / B **우리 모형이 최근 40줄의 되풀이 두 어절을 찾아 금지 목록으로 주고, 다듬기에서 화면 밖 장소·틀 문장·없는 말을 뺌 (채택)** / C 대사를 여러 개 받아 고름(호출 늘어남). 실제 호출: 화면 밖 장소("창밖", "발밑", "다리 사이")와 "짖!", "목 빠지는"이 나오는 것을 확인하고 걸러 내게 했다. 짧은 시나리오는 되풀이 기록이 적어 금지 목록이 비어 첫 반복은 막지 못한다(며칠 쓰면 쌓인다).
