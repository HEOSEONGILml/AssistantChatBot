# 검수 012 고치기

## 묶음 1: 평범한 말은 서운함이 아니다 (2026-10-19)

**고친 지적**: [중요] 평범한 말에 서운함이 크게 쌓이고 20분 넘게 풀리지 않는다 → 고침

**원인** (`probe-r12-phrases` 판단 로그):
- "아 아니다 됐어 신경 쓰지 마"에 Jev 시무룩↑ 0.37~0.48·친밀도↓ 0.23~0.40·속상함 0.45~0.53, "나 이제 일 좀 할게"에 시무룩↑ 0.15~0.34·친밀도↓ 0.19~0.30.
- 우리 모형이 직접 시무룩↑, 관계 해석(친밀도↓ × 0.8), 공감(속상함 × 0.35)을 더했다. 같은 서운함을 세 번 셌다.
- 20분 넘게 남은 것은 크기 탓이다. 시무룩 반감기(평균 약 21분)는 작은 서운함이면 눈에 띄지 않는다.

**설계 점검**:
- A. 기분 변화 질문 문구를 바꾸고 다시 녹화한다. 부탁을 거절로 읽는 경향은 문구로 잘 안 바뀐다(검수 011 사과 오독과 같은 꼴).
- B. 시무룩 반감기만 줄인다. 크기는 그대로라 "됐어" 한 마디에 0.4까지 오른다.
- C. 서운함 출처는 가장 큰 하나만 세고, 혼자 있게 해 달라는 부탁(hush, 이미 있는 질문)만큼은 서운함과 친밀도 하락에서 뺀다(**채택**). 같은 사건의 여러 읽기는 독립 증거가 아니니 최댓값이 맞다. 단독 실측에서 친밀도↓는 "됐어"와 "짜증나"를 가르지 못하고(0.47·0.47), 부탁은 가른다(0.58·0.14).

**바꾼 것** (기분 갱신 수식 스펙 3.11):
- 시무룩 Jev 조정 = max(Jev 시무룩↑, 0.35u, 0.8·친밀도↓) × (1 − hush) − 내림 쪽.
- 친밀도 변화의 친밀도↓ × (1 − hush).

**확인**:
- 테스트 5개 추가(일·됐어는 작게, 욕은 그대로, 세 출처 안 겹침, 부탁은 친밀도를 덜 내림). 두뇌 테스트 259개 통과.
- 시뮬레이션: 평균 끼어들기 0.27·답하기 0.83·먼저 말 걸기 0.33·연달아 0.11, 기분 고착 ≤ 0.10. 보정값은 그대로 뒀다(다시 맞춘 값이 답하기 0.89로 넘어 잡음 범위로 봤다).
- 실제 호출(probe-r12-phrases, Jev 58·Gemini 18): 시무룩 +0.01~0.02(전에는 +0.07~0.14), 예민 최고 0.47(전에는 0.76). 대사 "응, 방해하지 않을게".
- 남은 것: "됐어"에 "무슨 일인지 말하고 싶어지면 알려줘"처럼 속상함으로 읽는 대사는 지적 2(말 오독)에서 다룬다.
