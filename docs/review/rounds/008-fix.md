# 검수 008 고치기

## 묶음 1: 말하기 리듬(조각 끼어들기, 잦은 덧말) (2026-10-16)

**고친 지적**: [중요] 끼어들기가 거의 늘 첫 10글자 조각에서 나와 오독, [중요] 덧말이 잦다(약 40%) → 고침(덧말 해설 말투는 묶음 2)

**원인**: 화면은 10글자마다 타이핑 이벤트를 보내고, 첫 조각에서 이미 끼어들 수 있었다. 덧말 확률은 시뮬레이션에 맞췄는데 실사용이 시뮬레이션의 약 2배였다.

**설계 점검**: A 화면의 타이핑 이벤트 간격을 늘림(화면 수정, 반응성 저하) / B 두뇌가 15자 미만 조각에서 끼어들지 않음 + 덧말 시뮬레이션 목표를 실사용 차이만큼 낮춤(**채택**) / C 시뮬레이션 사용자 모형을 실사용에 맞게 다시 짬(원인 추정만 있고 근거 부족, 다음에). 

## 묶음 2: 말은 서운함을, 손길은 무서움을 (2026-10-16)

**고친 지적**: [중요] 사과 한 마디가 던져진 무서움을 쓰다듬기보다 몇 배 빨리 끈다 → 고침

**원인**: 검수 007에서 달램 계수를 0.5 → 0.8로 올리며 시무룩·분노·무서움에 똑같이 적용했다. 사과가 같은 묶음의 던지기 무서움까지 지웠다.

**설계 점검**: A 달램 계수를 다시 낮춤(검수 007의 "사과 뒤 서운함 그대로"가 돌아옴) / B 기분마다 달램 비율을 나눔: 시무룩 1, 분노 0.6, 무서움 0.25(**채택**, 개는 말보다 손길에 풀린다) / C 무서움 반감기를 늘림(던지기와 무관한 무서움도 오래 감).

## 남은 지적 (다음 고치기 회차)

- [중요] 놀란 직후 덧말로 "이제 괜찮아졌어"(해설)
- [중요] 반기는 말이 매번 "드디어 …"
- [사소] 집 역할 혼동, 활발 무서움·들뜸 1분, "놀자" 무응답 뒤 서운, 일한다는 주인에게 서운·"놀아줘" 반복, 무작위 두 강아지 자기소개 같음, 낮은 확률 동작 튐
