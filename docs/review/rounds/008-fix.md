# 검수 008 고치기

## 묶음 1: 말하기 리듬(조각 끼어들기, 잦은 덧말) (2026-10-16)

**고친 지적**: [중요] 끼어들기가 거의 늘 첫 10글자 조각에서 나와 오독, [중요] 덧말이 잦다(약 40%) → 고침(덧말 해설 말투는 묶음 2)

**원인**: 화면은 10글자마다 타이핑 이벤트를 보내고, 첫 조각에서 이미 끼어들 수 있었다. 덧말 확률은 시뮬레이션에 맞췄는데 실사용이 시뮬레이션의 약 2배였다.

**설계 점검**: A 화면의 타이핑 이벤트 간격을 늘림(화면 수정, 반응성 저하) / B 두뇌가 15자 미만 조각에서 끼어들지 않음 + 덧말 시뮬레이션 목표를 실사용 차이만큼 낮춤(**채택**) / C 시뮬레이션 사용자 모형을 실사용에 맞게 다시 짬(원인 추정만 있고 근거 부족, 다음에).
