# 검수 005 고치기

## 묶음 1: 이어 말하기는 우리 모형 (2026-10-16)

**고친 지적**: [중요] 1. 연달아 말하기가 너무 잦고 기계적, 과묵도 줄줄이 → 고침(같은 답 두 번은 묶음 2 대사 지시에서)

**원인**: 이어 말하기 확률을 Jev 말하기 확률 + 말수 + 보정값으로 정했다. 실제 Jev는 자기 말 뒤에도 말하기 확률을 높게 줘(녹화 시뮬레이션 28% vs 실사용 44%), 보정값으로 맞춘 값이 실사용에서 크게 빗나갔다. 말수가 로짓에 더해질 뿐이라 과묵한 강아지도 Jev가 높으면 이어 말했다.

**설계 점검**: A dog_spoke 보정값을 더 낮춤(녹화와 실제 차이가 그대로, 다시 빗나감) / B Jev를 다시 녹화(비용 240회, 차이 원인이 상황 차이면 해결 안 됨) / C **이어 말하기는 우리 모형: 평균 대비 말수와 횟수의 곱셈 모형, Jev 없이 (채택)**. 시뮬레이션과 실사용이 같은 식을 쓰므로 맞춘 값이 그대로 간다.

## 묶음 2: 주인의 슬픔에 공감 (2026-10-16)

**고친 지적**: [중요] 3. 주인의 슬픔에 궁금함·행복, 대답 안 함 → 고침(조언하는 말투는 일부 남음)

**원인·설계**: [스펙 3.6](../../superpowers/specs/2026-10-16-mood-update-math-design.md). Jev가 사용자 감정을 판단하고(새 Noul 질문), 공감은 우리 모형이 정한다. Jev 다시 녹화·보정. 실제 호출 확인: "너무 우울해"·"친구랑 크게 싸웠어"·"다 내 잘못 같아" 세 번 모두 반응 서운함, 속상함 0.94~0.95, 말할 확률 0.93~0.95로 모두 대답.

## 묶음 3: 지금 상황 사실 (2026-10-16)

**고친 지적**: [중요] 2. 주인이 곁에 있는지·누가 집에 들어갔는지 지어냄 → 고침

**원인**: 두뇌는 자리 비움(30분 간격 조용함)과 집 들고 남을 알지만 대사에 사실로 주지 않았다. Gemini는 이벤트 이름만으로 추측했다.

**설계 점검**: A 대화 규칙만 더함(이미 검수 003·004에서 했지만 되풀이됨) / B 두뇌가 아는 사실을 "지금 상황 사실"로 명시 + 집에서 나온 상황 지시를 주체 중심으로(**채택**) / C 대사 뒤 걸러내기(호출 늘고 근본 원인 그대로). 실제 호출 확인: 조용히 곁에 있는 주인에게 "뭐 해?", "아직 거기 있는 거 다 알아"; 집에서 나오면 다섯 경우 모두 "나 드디어 나왔다! 집 안은 너무 답답해서"처럼 자기가 나온 것으로 말함.

## 묶음 4: 사소 모음 (2026-10-16)

- "다시 말해 줘" 무시 → 물음표 없는 부탁(…줘/줄래/주라/봐로 끝남)도 질문으로 보고 +3.5.
- 말버릇·'화면'·사람 같은 말 → 대화 규칙: 컴퓨터 말 거의 금지, 손 대신 발·품 대신 곁.
- 끼어들기 뒤 같은 답 두 번 → 대화 규칙: 대화 기록에 이미 한 답은 되풀이하지 않음.
- 혼자 낮에 잠 안 듦 → 오래 혼자일 때 조용함의 졸림 0.06 → 0.10(정상 상태 기준값 +0.2 이상).
- 들뜸이 오래 감 → 들뜸 기본 반감기 10분 → 7분(평균 강아지 6분).
- 사과 중 서운함 → 판단: 고치지 않음. Jev가 "미안 일하느라 바빴"를 치는 중 친밀도↓·시무룩↑로 읽었고, 메시지를 보낸 뒤 관계 해석(친밀도↑ → 시무룩↓)으로 풀린다. 타이핑 중 글 일부만으로 사과를 가려내는 규칙은 오판이 더 클 수 있다.
