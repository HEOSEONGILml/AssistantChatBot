# 검수 006 고치기

## 묶음 1: 사과는 달램, 돌아오면 잠이 깬다 (2026-10-16)

**고친 지적**: [중요] 사과하면 더 서운해한다, [중요] 8시간 만에 돌아온 주인을 말로만 반긴다(몸은 졸린 채) → 고침

**설계 점검**: [스펙 3.7](../../superpowers/specs/2026-10-16-mood-update-math-design.md). A 사과 낱말 규칙(역할 중복) / B Jev 달램 질문 + 우리 모형이 풀림 정함(**채택**) / C 공감 계수 축소(진짜 슬픔 공감도 약해짐). 실제 호출 확인: 사과 두 번 모두 달램 0.89~0.92, 시무룩·무서움 내림.

## 묶음 2: 말하기 리듬 (2026-10-16)

**고친 지적**: [중요] 활발한 강아지가 일한다는 주인을 2시간 내내 조른다(21마디, 한 문장에 끼어들기 3번, 덧말 늘 0.9) → 고침

**원인**: 먼저 말 걸기가 대꾸 없음과 상관없이 같은 확률이었다. 끼어들기 횟수 제한이 없었다. 이어 말하기 상한 0.9에 활발한 강아지가 늘 붙었다.

**설계 점검**: A quiet 보정값만 낮춤(평소 먼저 말 걸기까지 줄어듦) / B 대꾸 없음 횟수만큼 로짓을 깎고(사용자 행동이 오면 회복), 끼어들기는 메시지당 한 번, 덧말 상한 0.6·목표 20%(**채택**) / C 일한다는 말을 알아듣는 규칙(글 해석, 역할 중복).

## 묶음 3: 날짜는 우리가 계산, 방금 한 말을 사실로 (2026-10-16)

**고친 지적**: [중요] "내일이 내 생일"을 다음 날 틀리게 계산, [중요] 방금 한 자기 말을 뒤집는다 → 고침(축하 표현은 성격·상황에 따라 "네 생일이잖아"로 나오기도 함)

**원인**: LLM이 대화 기록 시각과 지금 시각을 비교해 "내일"을 날짜로 바꾸는 계산을 자주 틀렸다. 끼어들며 한 말이 대화 기록 속 여러 줄 중 하나라 메시지 답에서 무시됐다.

**설계 점검**: A 규칙 문구만 강화(검수 004에서 이미 했고 되풀이) / B 상대 날짜를 우리가 실제 날짜로 바꿔 붙이고, 생일·방금 한 말을 "지금 상황 사실"로(**채택**, 계산·사실은 우리 몫) / C 사실 추출 기억 저장소(지금은 과함). 실제 호출 확인: 다음 날 두 성격 모두 "오늘이 바로 네 생일", "네 생일이잖아"; 사과/바나나는 끝까지 바나나.

## 묶음 4: 사소 모음 (2026-10-16)

- 겁먹은 덧말이 밝음 → 대사에 "지금 기분"(두드러진 기분의 말투: 무서우면 움츠러들어 밝게 말하지 않음 등).
- 연타 분노 0.90 → 한 묶음 안 같은 자극 k번째는 1/√k(스펙 3.8).
- 말투 군더더기 → 다른 동물 의성어('깡총')·'쿨럭' 금지, 주인이 하지 않은 행동 지어내기 금지.
- 집 역할 혼동 잔여 → 집에서 나온 상황 지시에 "주인이 어디 다녀온 것처럼 말하지 않는다".
- 하네스 '말하는 중' 단계 → `during_speech` 단계(앞 판단이 대사를 만드는 중일 때 보냄), 가짜 대사에 10ms 지연, 02-states에 "너 오늘 뭐 했어?" → "아 아니다 됐어" 추가.
- 판단: 걱정 반응이 '서운함'으로 찍힘 → 고치지 않음. 공감은 시무룩 기분의 표출이라 반응 어휘가 같다. 따로 '걱정' 반응을 두려면 반응 어휘·화면 그림·프로토콜(v3)을 바꿔야 해 사소 지적에 비해 비용이 크다.
- 판단: 놀아 줘도 들뜸 안 두드러짐 → 고치지 않음. "산책!"에 Jev가 행복↑를 크게 줘 행복이 두드러지고(다가가기 44%, 달리기 0.43, 놀기 19%) 움직임은 이미 활발하다. 들뜸 반감기(7분)가 행복(30분)보다 짧은 것은 의도다.
