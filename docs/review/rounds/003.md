### [사소] 9. 쓰다듬은 뒤의 편안한 행복이 마구 뛰는 움직임이 된다
- 관점: C2

- 사람이 기대하는 동작: 행복(편안한 기쁨)은 곁에 붙어 느긋하게 있는 쪽이다. 마구 뛰는 것은 들뜸의 몫이다.
- 재현 시나리오: `probe-pet-repeat.json`

### [사소] 10. 연타 뒤 분노가 끝에 붙고, 동작이 짖기 일색이다

## 체크리스트 판정

### A. 상태의 정합성
- **반대 기분 동시 0.5 이상**: 없음. 모든 분석표의 "반대 기분이 함께 높음"이 "없음"이다. 가장 가까운 경우는 사과 뒤 시무룩 0.51·행복 0.47(`probe-harsh-words`)과 예민 쓰다듬기 뒤 분노 0.42·행복 0.54(`04-personality`)다. → 통과
- **기분↔동작**: 대체로 맞다. 무서움일 때 approach 0~1%, 시무룩일 때 rest 67~89%, 졸림일 때 rest+sleep 93~96%다. 예외는 들뜬·무서운 강아지의 잠 동작(지적 8)이다. → 사소 결함
- **기분↔말투**: 사과 뒤 시무룩 0.5인데 밝은 말, 서운한데 "꼬리 살랑", 무서움 0.75인데 행복 반응(지적 7). → 사소 결함
- **끝에 붙음**: 연타 뒤 분노 0.92~0.96이 2분 30초 지속된다(지적 10). 그 밖에는 0.05~0.85 안에서 움직인다. 8시간 비움에도 심심함은 0.71이다. → 사소 결함

### B. 시간 감각
- **회복 시간**: 찌른 분노 45초~2분, 찌른 놀람 2분 15초, 던진 놀람 1분 30초~3분 30초, 던진 무서움 10~18분, 거친 말 시무룩은 6분 넘게 남는다. 개와 사람 감각으로 대체로 그럴듯하다. 놀람은 문서 목표(1분 안쪽)보다 약간 길다. 메시지 뒤 궁금함은 11~15분(`probe-bye-meeting`)으로 길지만 거슬리지는 않는다. → 대체로 통과
- **반응 시점**: 모든 반응이 이벤트와 같은 가상 시각에 나간다(인과 사슬의 시각 열). → 통과
- **하루·며칠 변화**: 2.6일 동안 기준값 변화는 ±0.002, 친밀도는 0.30→0.33이다(`03-time`). 하루 리듬으로 새벽 졸림 0.58, sleepy 경향 rest 60%·sleep 33%다. 적당하다. → 통과
- **오래 비운 뒤**: 돌아오면 행복 +0.11~0.21, 반기는 말이 나온다(좋음). 하지만 비운 동안 시무룩이 0.43~0.74까지 쌓여 있다(지적 1). → 중요 결함

### C. 인과와 크기
- **방향**: 쓰다듬기 → 행복↑ 분노↓, 거친 말 → 시무룩↑ 친밀도 0.30→0.27, 다정한 말·사과 → 행복↑. 방향은 모두 맞다. 예외는 조용함 → 서운함이다(지적 1). → 중요 결함(지적 1)
- **크기**: 찌르기 놀람 +0.16~0.24, 세게 던지기 무서움 +0.21~0.33이다. 친밀도는 이벤트당 최대 ±0.02로 안정적이다. 하지만 조용함 30분이 시무룩을 +0.15~0.24 올려 "저리 가 귀찮아"(+0.11)보다 크다. 사과는 시무룩을 −0.03만 내린다. → 결함
- **습관화**: 찌르기 30초 간격 5번 뒤 놀람 변화는 +0.02~0.03이고 짜증이 쌓인다(`probe-poke-spam`, 습관화 0.665). 쓰다듬기 6번 뒤 습관화 0.67, 행복 증가는 +0.14→+0.04다. 타이핑은 0.92까지 무뎌진다. 속도가 적당하다. → 통과
- **반응→동작→대사 한 줄기**: 대부분 이어진다(찌름 → 놀람·짖기 → "깜짝이야"). 끼어든 말과 답이 엇갈리는 경우가 있다(지적 6). → 대체로 통과

### C2. 다양성과 체감
- **분포의 한결같음**: 기본 세트 반응은 없음 87, 서운함 51, 행복 31, 궁금함 27, 놀람 24다. 동작은 엎드리기 73, 짖기 45, 앉기 42다. 짖기가 지배하지는 않는다. 하지만 조용함 반응은 서운함 일색이고(away-long 16/16, night-alone 13/18), 연타 동작은 짖기 8/8이다. → 결함(지적 1, 10)
- **자극과 반응**: 찌름·던짐에 들뜸이 나온 적은 없다(좋음). 던짐에 무서움 반응은 0번이다(지적 5). → 중요 결함
- **기분별 행동 체감**: 기분별 차이는 크다. sleepy rest 60~75%·달리기 0.05·머무는 시간 ×3.9~7.6, sad rest 67~89%·×2.5~6, excited roam 70%·달리기 0.68, scared rest 61~76%·approach 0~1%다. 눈에 보일 만하다. 다만 행복이 들뜸처럼 뛰고(지적 9) 성격별 평소 차이는 없다(지적 4). → 기분별 차이는 통과, 성격별 차이는 결함

### D. 성격
- **유형 간 차이**: 말한 수(04: 5/4/3/7, bye-meeting: 4/2/2/8)와 기분 수치(예민 분노 0.4, 활발 들뜸 0.7)는 다르다. 평소 움직임은 같고 활발이 가장 덜 뛴다(지적 4). 과묵의 말투가 다른 유형과 같다: "헤헤, 쓰다듬어 주니까 기분 좋다! 꼬리 살랑살랑~", "또 뭐 재미있는 거 할까? 킁킁, 어디 맛있는 거라도 숨겨놨어?"(04 과묵). → 중요 결함(지적 4). 말투 차이는 사소
- **성격과 반대 행동**: 과묵이 인사에는 답하지 않고 쓰다듬은 뒤 두 줄을 연달아 수다 떤다(04). 예민이 찔린 직후 쓰다듬기에 바로 "더 쓰다듬어 줘"라고 한다. 다만 분노 0.47은 기준값 0.4 근처라 크게 어색하지는 않다. → 사소
- **초기화 뒤**: 새 강아지 기준값은 궁금함 0.25, 행복 0.23, 놀람 0.21, 변덕 0.68이고, 말수는 1.54→0.80이다(`02-states` get_state). 분명히 다른 강아지다. 표본이 하나라 분포는 판단하지 않는다. → 통과
