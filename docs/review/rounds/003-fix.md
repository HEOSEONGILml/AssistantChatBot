**고친 지적**
- [중요] 1. 조용하면 서운해한다 → 고침(자리 비운 조용함은 서운함 0, 미답 서운함은 한 번만, 조용함 Jev 가중치 0.1)
- [중요] 5. 세게 던져도 무서움 반응이 없다 → 고침(무서움 사전값 > 놀람, 던지기 습관화 대상 놀람)

**설계 점검**: A 미답 가산 제거(진짜 무시도 사라짐) / B 조용함의 뜻을 자리 있음·없음으로 나누고 미답은 한 번, 조용함은 우리 몫, 던지기 무서움 우선(**채택**) / C 작별 인사 글 해석(역할 중복). [스펙 3.4](../../superpowers/specs/2026-10-16-mood-update-math-design.md).

## 묶음 2: 대사 지시 (2026-10-16)

**고친 지적**: [중요] 2. 오지 않은 복귀를 지어냄, [중요] 3. "10분" 읊기·존댓말, [중요] 6. 선택 뒤집기·역할 바꾸기, [사소] 7 일부(기분과 안 맞는 꼬리 살랑) → 고침

**원인**: 조용함 상황 지시가 "먼저 말을 건다"뿐이라 사용자가 돌아왔다고 지어냈다. 조용함 맥락의 초(600)와 기록 줄의 "(시간(초) 600)"을 실제 경과로 읽었다. 반말·일관성·몸짓 규칙이 없었다.

**설계 점검**: A Jev 상태에서 조용함 초를 뺌(Jev 분포가 바뀌어 녹화·보정 다시) / B 대사 프롬프트에서만 조용함 초를 빼고 규칙을 더함(**채택**, 녹화 유지) / C 대사 뒤 걸러내기(호출 늘고 원인 그대로). 실제 호출 확인: "너라면 뭐 골라?" → "난 기름진 짜장면", "아까 뭐라고 물어봤는지 기억해?" → "아까 점심 뭐 먹을지 물어봤잖아, 김치찌개랑 짜장면"(역할 맞음), 위로 요청에 곁에 있음.
