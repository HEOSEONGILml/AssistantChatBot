# 검수 004 고치기

## 묶음 1: 대사의 기억과 일관성 (2026-10-16)

**고친 지적**: [치명] 1. 하지 않은 말을 지어내고 고른 것을 뒤집는다, [중요] 2. 하룻밤 지나면 생일을 잊는다, [중요] 3. 역할 혼동(던져진 쪽·집에 들어간 쪽), [사소] 9. 곁에 있는 주인에게 "어디 갔어?" → 고침

**원인**: Gemini가 받는 과거는 이벤트 기록 30개(타이핑·조용함·반응 줄이 섞임)와 자기 말 5개뿐이었다. 하룻밤 사이 이벤트가 쌓이면 들은 사실이 창 밖으로 밀렸다. 무엇이 실제로 오간 말인지 구분이 없어 "했잖아"를 지어냈다. 던져진 것·집에 들어간 것의 주체를 정하지 않았다.

**설계 점검**

| 안 | 내용 | 판단 |
|---|---|---|
| A. 이벤트 창을 30 → 100으로 | Jev 상태도 커짐(분포 바뀜, 녹화·보정 다시), 잡음 줄도 늘어남 | 기각 |
| B. 사실 추출 기억(이름·생일을 따로 저장) | 추출 규칙·모델이 필요, 지금은 과함 | 보류 |
| C. **대사 프롬프트에만 대화 기록(실제 오간 말 20줄, 시각 포함) + 정직·기억·주체 규칙 (채택)** | Jev 녹화 유지, 단순 | 채택 |

**실제 호출 확인**: 사과/바나나 — 끼어들며 "사과!", 질문에 "사과가 더 좋아", 이유도 사과로 유지. 이름·고양이·생일 — 다시 켠 다음 날 "민수야 좋은 아침! 오늘은 바로 민수 생일이지", "고양이 키운다고 했잖아".

## 묶음 2: 기분끼리의 상호작용 (2026-10-16)

**고친 지적**: [중요] 4. 무서움·들뜸 함께 높음, [중요] 5. 성마른 강아지가 더 크게 행복, [중요] 6. 혼잣말 질문 뒤 서운함 되풀이, [사소] 11. 무서움 0.84에 행복 반응, [사소] 12 일부(연타 궁금함 상승, 분노 증가 완화) → 고침

**설계 점검**: A 점프 억제만 키움(검수 002 결함 회귀) / B 결합 OU(반대 기분이 돌아갈 자리를 누름) + 절대 수준 경계 + 대화 흐름 질문만 기다림(**채택**) / C 반대 쌍을 한 축으로(기분 9개 컨셉 위반). [스펙 3.5](../../superpowers/specs/2026-10-16-mood-update-math-design.md).

## 묶음 3: 질문·속상한 이야기에는 대답 (2026-10-16)

**고친 지적**: [중요] 7. 메시지 무응답 31%, 속상한 이야기·직접 질문에 침묵 → 고침

**원인**: 말할 확률이 메시지의 종류(질문인지, 털어놓는 말인지)를 몰랐다. Jev 말하기 확률이 0.6~0.9여도 보정값과 말수에 따라 30%가량 침묵했다.

**설계 점검**: A 메시지 보정값만 올림(평범한 말에도 다 대답해 강아지답지 않음) / B 질문·속상한 이야기에만 로짓 +3, 전체 목표 85%는 시뮬레이션으로 맞춤(**채택**: 중요한 말엔 대답, 평범한 말엔 가끔 무응답) / C 질문엔 반드시 대답(확률 모형을 벗어남, 변덕 사라짐). 판단: 실사용과 시뮬레이션의 차이는 다음 검수에서 다시 본다.

## 묶음 4: 성격별 말투 (2026-10-16)

**고친 지적**: [중요] 8. 대사가 상투적이고 성격마다 말투가 같다 → 고침(상투 문장은 일부 남음: "손길 따뜻")

**원인**: Gemini는 성격 수치(기준값)만 받았고, 그 수치를 말투로 옮기는 지시가 없었다. 기본 성격 문구("호기심 많고 수다스러운")가 모든 강아지에 같았다.

**설계 점검**: A 수치만 더 강조(LLM이 수치를 말투로 잘 옮기지 못함) / B 우리 모형이 기준값에서 말투 지시와 문장 수를 만듦(**채택**, 0015처럼 해석은 우리 몫) / C 성격 유형별 고정 대사 틀(다양성이 사라짐). 실제 호출 확인: 과묵 "기분 좋아, 멍." / 예민 "계속 건드리면 나 화낼 거야, 왈!" / 활발 "와! 너랑 놀 생각에 벌써 엄청 신나!".

## 묶음 5: 사소 모음 (2026-10-16)

- 10. 밤에 잠 동작 0 → 하품 반응이 잠으로도 이어지게(엎드리기 0.6, 잠 0.8). 졸림이 평소보다 0.3 높으면 조용함에 잠 20% 넘게.
