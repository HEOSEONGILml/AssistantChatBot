  - 판정: 대체로 맞음. 하품 + 짖기·조르기는 어긋남(사소). 타이핑 중 자세 바뀜(중요).
  - 근거: 던지기 → 엎드리기 28/30. 쓰다듬기 → 조르기 18/37. 겁먹은 강아지는 쓰다듬어도 조르지 않는다(`probe-r12-throw-ok`: 4마리 모두 엎드리기).
- 기분과 말투
  - 판정: 맞음.
  - 근거: 던진 뒤 예민 "아직도 심장이 콩닥거려", 활발 "아직 조금 덜덜 떨리긴 하는데 … 금방 나아질 것 같아". 겁먹은 강아지는 대부분 입을 다문다(`probe-scared-pet` 대사 0개).
  - 예외: `probe-throw-sorry`에서 무서움이 0.21(기준값 0.10)일 때 "괜찮아! 이제 다시 기운 났어"라고 했다. 크게 어긋나지는 않는다.
- 끝에 붙음
  - 판정: 없음.
  - 근거: `03-time`의 밤 들뜸이 0.02~0.16 사이에서 움직이고, 아침에 회복한다. 다른 값도 0·1에 붙지 않는다.

### B. 시간 감각
- 반쯤 회복
  - 판정: 몸 자극은 적절하다. 말로 생긴 시무룩이 너무 길다(중요).
  - 근거
    - 놀람 2~3분.
    - 찔린 분노: 초과분이 작으면 2분, 예민한 강아지 0.42는 13~15분.
    - 던진 무서움: `01`에서 11분 뒤 0.38 → 0.21.
    - 반김(들뜸): 40~50분.
    - 시무룩: 22분째 안 풀림.
- 반응 시점
  - 판정: 즉시.
  - 근거: 반응·동작은 이벤트 직후에 나온다. 대사는 같은 판단 안에서 나온다(인과 사슬 시각이 같다).
- 하루·며칠 단위 변화
  - 판정: 적절.
  - 근거: `03-time` 2.6일 동안 기준값 변화는 ±0.005, 친밀도는 0.30 → 0.33이다.
- 오래 비운 뒤
  - 판정: 그럴듯하다.
  - 근거
    - `03-time`: 1시간 자리를 비우는 동안 심심함 0.68. 돌아오면 들뜸 0.60으로 반긴다("기다렸잖아, 어디 다녀왔어?").
    - `probe-away-long`: 8시간 동안 심심함 → 잠. 돌아오면 "이제야 돌아왔네!"
    - 밤(23시~)에는 졸림 0.5~0.6, 움직임은 sleepy(쉬기 66%, 잠 32%)다.

### C. 인과와 크기
- 원인과 결과
  - 판정: 몸 이벤트는 맞다. 말은 어긋난다(중요). "일 좀 할게" → 시무룩↑, "됐어" → 위로.
  - 근거: 찌르기 → 놀람 26/35, 연타 → 짜증. 쓰다듬기 → 행복. 돌아옴·집에서 나옴 → 신남 22/22.
- 크기
  - 판정: 몸 자극은 맞다. 말의 시무룩이 크다.
  - 근거: 던지기 1.0 → 무서움 +0.26~0.40(성격별). 찌르기 → 놀람 +0.14~0.23. 친밀도 변화는 판단당 0.01 이하다.
- 습관화
  - 판정: 적절.
  - 근거: `probe-poke-spam`(예민) 13번 찔렀을 때 대사는 1번, 그 뒤로는 짜증이다. `probe-poke-active` 세 번째 찌르기에 "그만 좀 해, 이제 진짜 화나려고 해".
- 한 줄기
  - 판정: 대체로 이어진다. 시킨 동작에서 말과 동작이 끊기는 일이 있다(중요).

### C2. 다양성과 체감
- 동작 분포
  - 판정: 이벤트별로 다르다(사소: 찌르기는 짖기, 던지기는 엎드리기로 쏠림).
  - 근거: 메시지 판단 196번의 동작은 서기 99, 앉기 49, 조르기 15, 엎드리기 14, 없음 11, 짖기 8. 조용함은 7가지 동작에 고르게 퍼졌다.
- 반응과 자극
  - 판정: 맞음.
  - 근거: 던지기 → 무서움 29/30, 찌르기 → 놀람·짜증. 들뜸이 나온 경우는 없다.
- 기분별 움직임 체감
  - 판정: 체감된다.
  - 근거(`03-time`): sleepy는 쉬기 66%·잠 32%·달리기 0.01·머무는 시간 ×9.0, excited는 돌아다니기 60%·놀기 20%·달리기 0.69·머무는 시간 ×0.11. scared는 쉬기 60%·다가가기 3%(`01`). 성격별로 평온할 때 쉬기는 활발 10%, 평균 29%, 과묵 51%다(`04`).

### D. 성격
- 유형 차이
  - 판정: 느껴진다.
  - 근거(`04`): 같은 "안녕 기분 어때?"에 평균 "너랑 같이 있으니까 기분이 아주 좋아", 과묵 "기분 좋아, 멍.", 예민 "그냥... 평소랑 똑같아.", 활발 "완전 신나! 왈!" + 덧말. 같은 시나리오에서 말할 확률은 활발 0.93, 예민 0.43이다.
- 성격과 반대 행동
  - 판정: 못 봤다.
  - 근거: 예민한 강아지는 쓰다듬어도 "손길이... 나쁘지는 않네"라고 한다. 과묵한 강아지는 끝까지 한 문장이다.
- 초기화
  - 판정: 다른 강아지가 된다.
  - 근거: `02-states` 초기화 뒤 기준값 심심함 0.71, 들뜸 0.56, 졸림 0.09, 말수 1.21 → 2.67.

### E. 대사
- 어색함·번역투
  - 판정: 일부 있다.
  - 근거: "새로 옮겨 다니는 마우스 커서도 따라다녀 보고 싶고"(`02`), "이봐, 언제까지 가만히 있을 거야?"(`04` 활발).
- 반복
  - 판정: 대체로 없음.
  - 근거: 두 번 반복은 있다. `probe-night-return`에서 "조금만 더 … 안 될까?"가 10분 사이에 두 번, `probe-happy-chat-bored`에서 같은 결의 다정한 말이 세 마디 연달아 나왔다.
- 맥락 무시·오해
  - 판정: 있음(중요). 위 지적 참고.
- 기억
  - 판정: 좋음.
  - 근거: 다음 날 생일(`03`, `probe-birthday-nextday` 3/4), 이름·고양이(`probe-memory-ask`), 고른 것 유지(`probe-consistency`, `probe-choice-interrupt`). 다시 켠 뒤에도 기억한다(`03` restart → "오늘이네, 생일 축하해!").
- 답 기다림
  - 판정: 지킨다.
  - 근거: 질문으로 끝난 말 뒤에 이어 말할 확률이 0.0이다(`02`, `03` 인과 사슬). 혼잣말 질문 뒤에는 이어 말한다.

### F. 리듬
- 끼어들기
  - 판정: 적당하다.
  - 근거: 긴 글 12번(`probe-r12-typing-long`)에서 3번 끼어들었다(활발 2, 평균 1, 과묵·예민 0). 메시지 하나에 한 번이다.
- 먼저 말 걸기
  - 판정: 평균은 적당하다. 활발은 많지만 성격으로 볼 만하다.
  - 근거: `probe-r12-quiet-2h`(평균) 2시간에 2번. `probe-ignored-active`(활발) 1시간에 4번, 말할 확률이 0.67 → 0.51 → 0.37 → 0.22 → 0.12로 줄어든다.
- 연달아 말하기
  - 판정: 대체로 자연스럽다.
  - 근거: 활발은 세 마디가 가끔(상한 4번), 과묵은 거의 한 마디다.
- 무응답
  - 판정: 자연스럽다.
  - 근거: 메시지 무응답 28번. 예민·과묵이 대부분이고, 대신 반응·동작은 낸다.

### G. 실패와 예외
- 키·호출 실패
  - 판정: 문제없음.
  - 근거(`02-states.jsonl`): 호출 실패 때 찌르기에 놀람·엎드리기, 키 오류 때 `bad_key` 상태와 짜증 반응, 키 없음 때 `no_keys`. 대사는 없고 상태는 이어진다.
- 집
  - 판정: 조용하다. 나오면 반긴다.
  - 근거: `02` 집 안 10분 동안 판단 0번, 나오면 "다시 나오니까 반갑네!". `probe-house-toggle` 2초 넣었다 빼기도 문제없다. 나온 뒤 대사에 역할 혼동이 가끔 있다(중요 지적에 포함).
- 몰아치기
  - 판정: 엉키지 않는다.
  - 근거: `02` 찌르기 + 메시지를 한 묶음으로 판단했다("앗, 갑자기 쿡 찌르니까 깜짝이야! … 그냥 서서 구경하고 있었어"). 말하는 중에 온 메시지는 대사를 버리고(커버리지 1), `probe-burst-mixed` 찌르기·던지기·쓰다듬기·사과를 한 번에 처리했다.
- 연결 끊김·다시 켬
  - 판정: 문제없음.
  - 근거: 끊긴 2분 동안 판단이 없다. 다시 붙으면 `status ok`, 다시 켜면 기억 30줄이 남는다.
