# 검수 007 고치기

## 묶음 1: 겁먹은 상태가 행동을 누른다 (2026-10-16)

**고친 지적**: [중요] 겁먹은 강아지가 쓰다듬기에 기쁨 반응·조르기, [중요] 활발한 강아지가 겁에 질려서도 쉬지 않고 말함, [사소] 무서움·들뜸이 잠깐 함께 0.5 → 고침

**설계 점검**: [스펙 3.9](../../superpowers/specs/2026-10-16-mood-update-math-design.md). A 무서움 반감기만(기쁨 반응 그대로) / B 경계를 Jev 기쁨에도 + 반응 막음 + 조르기·말하기·덧말 억제(**채택**) / C 판단 건너뜀(맞는 반응도 사라짐).

## 묶음 2: "말 걸지 마"를 지킨다 (2026-10-16)

**고친 지적**: [중요] "말 걸지 마"라고 해도 10분 만에 먼저 말을 건다 → 고침

**원인**: 말 걸지 말라는 부탁을 판단·기억하는 곳이 없었다. **설계 점검**: A 낱말 규칙(글 해석은 Jev 몫) / B Jev 질문 hush + 우리 모형이 1시간 기억·로짓 −5(**채택**) / C 강아지가 집에 들어가게(사용자 행동을 대신 정함, 컨셉 변경 큼). 다시 녹화·보정. 실제 호출: hush 0.65~0.97, 1시간 대사 평균 4·과묵 1·예민 1·활발 5(전 활발 6마디+, 네 성격 모두 10분 만에 말 걸기).

- [중요] 끼어들기가 덜 친 글을 엉뚱하게 읽는다
- [중요] 반기는 말이 늘 같은 틀이다
