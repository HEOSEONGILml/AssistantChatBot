# 0020. 두뇌 규칙을 최소로 남긴다

- 상태: 채택
- 날짜: 2026-10-20

## 배경

0018·0019 뒤에도 기분·반응·동작·말하기·대사에 검수 회차마다 붙인 예외 규칙이 남아 있었다. Claude가 영역별로 덜어낼 것을 제안했고 사용자가 전부 수용했다 (2026-10-20). 여유 비례는 되살리지 않기로 했다(사용자).

## 결정

| 영역 | 남기는 것 |
|---|---|
| 기분 (이벤트) | 글 없는 사건은 고정 평가값, 글은 0.3 × P_Jev(기분). 반대 기분 같은 양 억제. 더하고 0~1로 자른다 |
| 기분 (시간) | 기분별 반감기로 고정 자리 `REST`에 돌아간다 |
| 반응 | 가장 크게 오른 기분이 0.03 이상이면 그 반응. 타이핑이면 늘 하나(없으면 궁금함) |
| 동작 | 기본 + 이벤트 사전값 + 기분 + 반응 친화도. 메시지만 Jev 동작 로그확률 × 1.5. 잠은 졸릴 때만. 자기 말 뒤에는 없음 |
| 말하기 | σ(logit P_Jev + β[종류] − 연달아 횟수). 연달아 3번이면 0 |
| 이어 말하기 | chain_base × 0.3^(k−1) |
| 흐름 상태 | 집 안, 이번 메시지에 끼어듦, 자리 비움 |
| 대사 사실 | 주인이 곁에 있다 / 자리를 비웠다 / 방금 돌아왔다 |
| 대사 다듬기 | 줄바꿈·이름표·따옴표 정리, 앞의 두 문장 |

삭제: 포화 합산, 1/√k, 쓰다듬기 경계, 쓰다듬기 시간·조용함 시간·돌아옴 비운 시간에 따른 가변값, 시간 중 반대 기분 누르기, 흔들림, 자리 바닥, 하루 리듬, 이미 놀람 덜 드러냄, 겁먹으면 기쁨 반응 막기, 메시지 아닌 이벤트의 Jev 동작, 듣는 동안 자세 유지, 질문·서운함 대답 보정, 대꾸 없음 감점, 겁 감점, 기다림 감점·답 기다림 상태, 이어 말하지 않음 상태, 이어 말하기의 겁·대꾸 없음 감쇠, 대사의 집·떠나기 전 말·주인 말·생일·방금 한 말 사실, 금지어·몸짓·틀 걸러내기, 의성어뿐인 대답 다시 묻기·버리기.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 여유 비례 되살리기 | 기분이 끝에 붙지 않는다 | 규칙 하나 더 | 사용자가 거절 |
| 영역별로 나눠 단계적으로 | 효과를 하나씩 본다 | 녹화·보정을 여러 번 | 사용자가 전부 수용 |
