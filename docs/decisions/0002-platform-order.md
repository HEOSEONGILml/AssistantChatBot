# 0002. Windows PC를 먼저 만들고, Android는 그다음에 만든다

- 상태: 채택
- 날짜: 2026-10-14

## 배경

PC와 모바일 배경화면 모두가 목표다. 플랫폼마다 "배경화면에 캐릭터가 산다"를 구현하는 방식이 완전히 다르다. 그래서 순서를 정해야 했다.

## 결정

Windows PC를 먼저 완성한다. Android는 사용자가 Windows 완성을 판단한 뒤 별도로 지시할 때 착수한다. 사용자가 지정한 사항이다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 처음부터 크로스플랫폼 | 코드를 공유할 수 있다 | 플랫폼별 배경화면 제약을 동시에 풀어야 한다 | 사용자가 순차 진행을 선택했다 |

## 결과

- Windows 설계에 Android 고려 사항을 미리 넣지 않는다 (YAGNI).
- 다만 Jev 판단 로직처럼 플랫폼과 무관한 부분은 UI와 분리해 둔다. 이건 Android 대비가 아니라 테스트하기 쉽게 하려는 것이다.
- macOS와 iOS는 현재 범위 밖이다.
