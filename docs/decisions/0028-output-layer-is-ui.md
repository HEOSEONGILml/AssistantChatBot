# 0028. 출력 계층은 사용자 인터페이스만 맡고, 컴퓨터에 행동하는 것은 백엔드가 한다

- 상태: 채택
- 날짜: 2026-10-21

## 배경

에이전트에서 나오는 것은 두 가지다.

- **알리기**: 진행 상황, 질문, 결과, 실패를 사용자에게 보여 준다.
- **행동하기**: 브라우저 클릭, 글자 입력, 페이지 이동처럼 컴퓨터에 직접 행동한다. 1단계에서는 Claude Code가 크롬 확장으로 한다.

출력 계층의 범위를 정해야 했다.

## 결정

- 출력 계층은 **사용자 인터페이스**만 해당한다. 입력 계층처럼 프론트다.
- 컴퓨터에 **행동하는 것은 백엔드**가 한다.

사용자가 정했다.

```mermaid
flowchart LR
  I["입력 계층<br>프론트"] --> BE["백엔드<br>에이전트 · 행동"]
  BE --> O["출력 계층<br>프론트"]
```

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 출력 계층이 알리기와 행동하기를 모두 맡는다 | 에이전트에서 나오는 것을 한곳에 모은다 | 출력 계층에 프론트와 컴퓨터 조작이 섞인다 | 사용자가 출력 계층은 사용자 인터페이스만이라고 정했다 |

## 결과

- 입력 계층과 출력 계층은 프론트, 에이전트와 행동은 백엔드다.
