# 0005. 대화 기록은 PC에만 저장한다

- 상태: 채택
- 날짜: 2026-10-14

## 배경

대화 기록을 어디에 둘지에 따라 서버가 필요한지, API 키를 어디에 둘지가 달라진다.

## 결정

대화 기록은 사용자 PC에만 저장한다. 서버를 두지 않고, 앱이 Jev와 LLM을 직접 호출한다. 사용자가 지정한 사항이다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 서버에 저장 (Bigglz-AI-core 등) | 키가 숨겨진다. 기기 간 동기화가 가능하다 | 서버를 운영해야 한다. 지연이 늘어난다 | 사용자가 로컬 저장을 선택했다 |
| 로컬 저장 + 서버 중계 | 키가 숨겨진다 | 중계 서버가 필요하다 | 사용자가 로컬 저장을 선택했다 |

## 결과

- 대화 내용은 PC 밖으로 나가지 않는다. 예외는 Jev와 LLM 호출에 담겨 전송되는 내용이다.
- **API 키가 PC에 놓인다.** 키는 저장소에 커밋하지 않고 로컬 설정에서 읽는다. 앱을 다른 사람에게 배포하게 되면 키 노출 문제 때문에 이 결정을 다시 검토한다.
- Android로 확장할 때 기기 간 대화 이어가기는 지원하지 않는다. 필요해지면 그때 다시 검토한다.
