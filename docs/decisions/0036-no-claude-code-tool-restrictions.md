# 0036. Claude Code 기본 도구를 끄지 않고, 브라우저에 국한하지 않는다

- 상태: 채택
- 날짜: 2026-10-22
- 수정: [0029](0029-claude-code-harness-and-session-per-task.md)의 "끄는 도구"와 하네스 1절(역할)

## 배경

[0029](0029-claude-code-harness-and-session-per-task.md)는 `disallowed_tools`로 `Bash`, `Write`, `Edit`, `NotebookEdit`, `Task`, `Skill`을 껐다. 브라우저 밖의 파일·명령을 건드리지 않게 하려던 Claude의 정의였다. 직접 써 보니 조수가 "터미널 명령을 실행할 수 없다"고 답했다. 사용자가 기본 Claude Code의 기능을 제약하지 말고, 브라우저로 국한하지 말라고 했다 (사용자, 2026-10-22).

## 결정

`disallowed_tools`를 두지 않는다. Claude Code 기본 도구를 모두 쓴다. 하네스의 역할도 브라우저 조작에 국한하지 않는다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 도구를 계속 끈다 | 파일·명령을 건드릴 일이 없다 | 터미널 명령 같은 기본 일을 못 한다 | 사용자가 제약하지 말라고 했다 |

## 결과

- 확인은 권한 모드(설정 탭)와 하네스의 질문 규칙을 따른다.
- `setting_sources=[]`은 그대로다. 도구를 끄는 설정이 아니라 이 PC의 사용자 스킬·플러그인·CLAUDE.md를 섞지 않는 설정이다.
