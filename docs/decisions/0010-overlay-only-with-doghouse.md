# 0010. 배경 모드를 빼고 오버레이 모드만 두며, 대신 "강아지 집" 비활성 모드를 둔다

- 상태: 채택
- 날짜: 2026-10-14
- 대체: [0003](0003-windows-display-modes.md)의 배경 모드, [0009](0009-background-mode-wallpaper-replacement.md) 전체

## 배경

[배경 모드 스파이크](../spikes/background-mode.md)에서 오버레이 모드는 바로 동작했다. 배경 모드는 투명이 안 돼 배경화면을 앱이 직접 그려야 했고, 탐색기 재시작, 비정상 종료 시 검은 바탕화면, 화질 저하 등 처리할 일이 많았다.

사용자가 사용성 측면에서 다시 판단했다. 배경 모드에서는 강아지를 보려고 모든 창을 내려야 해서 불편하다. 그러면 끼어들기와 선발화도 사용자가 알아차리기 어렵다.

## 결정

- **배경 모드를 뺀다.** Windows 앱은 항상 위에 떠 있는 투명 창(오버레이)만 쓴다.
- 대신 **"강아지 집" 비활성 모드**를 둔다. 사용자가 집중하고 싶을 때 강아지를 집에 넣어 화면에서 치울 수 있다.

사용자가 정한 사항이다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 두 모드 유지 (0003 + 0009) | 진짜 배경화면 같은 경험 | 구현이 복잡하다. 강아지를 보려면 창을 다 내려야 한다 | 사용성과 비용 모두 불리 |
| 오버레이만, 숨김 기능 없음 | 가장 단순하다 | 집중하고 싶을 때 치울 방법이 없다 | 사용자가 비활성 모드를 원했다 |

## 결과

- 몸체 범위가 줄어든다. 서브 프로젝트 1b(배경 모드)는 없어지고, 0009의 과제는 모두 필요 없다.
- 배경 모드 클릭 감지(마우스 훅), 배경화면 대체, WorkerW 처리가 필요 없다.
- "보이지 않을 때"는 이제 주로 **강아지가 집에 있을 때**와 사용자가 자리를 비웠을 때다. 강아지 집에서의 동작(말을 거는지, 집은 어떻게 보이는지, 어떻게 꺼내는지)은 vision에서 정한다.
- 0004의 "배경 모드에서도 클릭으로 입력창 열기"는 오버레이 모드 클릭만 남는다.
- 0003의 "모드는 사용자 설정으로 고정"은 표시 모드가 하나뿐이라 의미가 없어진다. 대신 강아지 집에 넣고 꺼내는 것은 사용자가 그때그때 한다.
