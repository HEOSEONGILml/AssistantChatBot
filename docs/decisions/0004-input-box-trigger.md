# 0004. 캐릭터 클릭이나 전역 단축키로 입력창을 열고, 상시 표시 여부는 설정으로 정한다

- 상태: 채택
- 날짜: 2026-10-14

## 배경

사용자는 타이핑으로 캐릭터에게 말을 건다. 입력창을 여는 방법이 필요하다.
배경 모드에서는 캐릭터가 바탕화면 아이콘 뒤에 있어 클릭이 캐릭터 창에 바로 전달되지 않는다.

## 결정

- 캐릭터를 클릭하거나 전역 단축키를 누르면 입력창이 열린다. 배경 모드와 오버레이 모드 모두 해당한다.
- 입력창을 상시 표시할지는 사용자 설정으로 정한다.

사용자가 지정한 사항이다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 단축키만 | 두 모드에서 구현이 같다 | 캐릭터를 직접 만지는 느낌이 없다 | 사용자가 클릭도 원했다 |
| 오버레이 모드에서만 클릭 | 구현이 쉽다 | 모드마다 동작이 다르다 | 사용자가 두 모드 모두 클릭을 원했다 |

## 결과

- **배경 모드의 클릭 감지는 기술 검증이 필요하다.** 아이콘 뒤 레이어에 있는 창은 클릭을 직접 받지 못한다. 바탕화면이 보일 때 마우스 훅 같은 방법으로 클릭 위치가 캐릭터 영역인지 판정해야 할 수 있다. 구현 설계 때 스파이크로 확인한다.
- 단축키 조합은 사용자가 바꿀 수 있어야 하는지 나중에 정한다.
- 입력창을 상시 표시하는 설정은 배경 모드에서 입력창이 다른 창에 가려지는 문제와 함께 다룬다.
