# 0014. Jev는 분포를 주고, 확률 모델이 뽑아서 결정한다

- 상태: 채택 (성격 파라미터 부분은 [0018](0018-simplify-to-reaction-and-mood.md)로 대체)
- 날짜: 2026-10-15
- 수정: [0001](0001-jev-as-decision-engine.md)의 "Jev가 결정한다" → "Jev는 판단 분포를 주고 결정은 확률 모델이 한다"

## 배경

v1은 Jev 응답에서 1등만 고르고 `speak_now`를 임계값 하나와 비교했다. 실측해 보니 Jev 점수는 같은 상황이면 거의 같아서(±0.02), 같은 상황에서 늘 같은 행동이 나왔다([실측](../spikes/2026-10-15-jev-speak-now-probe.md)).
사용자는 코드 규칙만도, Jev 판단만도 아닌 "확률 모델과 Jev의 결합"을 원했다.

## 결정

- **Jev는 결정하지 않고 분포를 준다.** 이벤트 하나에 Jev 호출 한 번으로 반응 분포, 동작 분포, 말할 확률, 기분·친밀도 변화 분포를 받는다.
- **확률 모델이 분포에서 뽑아 결정한다.** 같은 상황에서도 가끔 다르게 행동하되, 그 우연은 Jev 판단에 근거한다.
- 강아지 상태는 네 층이다: 반응(이벤트), 기분(수치 5차원: 심심함·졸림·들뜸·시무룩·분노), 친밀도(수치 1차원), 성격(확률 모델의 파라미터).
- 시간에 따른 기분 변화는 평균 회귀 확률 과정(기준값으로 돌아가며 흔들림)이 맡는다.
- 성격은 태어날 때 무작위로 뽑고, 겪은 일로 천천히 변한다.
- 파라미터는 녹화한 Jev 분포로 시뮬레이션해 목표 지표에 맞춘다.

층 구분, 기분 수치화, 우연 섞기, 무작위 탄생, 시뮬레이션은 사용자가 정했다. 분포를 뽑아 쓰는 방식, 평균 회귀 과정, 성격 = 파라미터는 Claude가 제안하고 사용자가 수용했다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 1등 선택 + 임계값 (v1) | 단순하고 설명하기 쉽다 | 같은 상황이면 늘 같은 행동 | 기계적이다 (실측) |
| 코드 규칙으로 기분 변화 | 싸고 예측 가능 | 말의 내용을 모른다 | 사용자가 원하지 않음 |
| 반응·동작·발화를 한 질문으로 묶고 그룹별 정규화 | 질문 수가 준다 | 한 그룹이 확률을 몰아가면 다른 그룹 몫이 0.01까지 무너진다 | [실측](../spikes/2026-10-15-brain-v2-assumptions.md)에서 깨짐 |
| 기분을 자연어로 | 풍부하다 | 바꿀 때마다 LLM이 다시 써야 한다 | 쌓임·풀림·확률과 연결하기 어렵다 |

## 결과

- 행동을 "한 번"이 아니라 "여러 번의 분포"로 평가해야 한다. 시뮬레이터가 필요하다.
- 강아지 상태(기분·친밀도·성격)를 두뇌가 저장한다.
- 감정별 그림은 반응×동작 조합이 된다.
- 설계: [두뇌 스펙 v2](../superpowers/specs/2026-10-15-brain-v2-design.md)
