# 0016. 동작 선택은 우리 모형 중심, Jev는 약한 조정

- 날짜: 2026-10-16
- 상태: 채택 (검수 루프 결정, [검수 001](../review/rounds/001.md))
- 고치는 결정: [0014](0014-probabilistic-model-with-jev-distributions.md)의 동작 부분

## 맥락

검수 001에서 동작이 판단 168번 중 서기 130번이었다. Jev 동작 분포가 서기 0.83~1.00이었고, 점수에서 Jev 로그확률 차이(약 5)가 우리 보정(±0.5)보다 열 배 컸다.

## 결정

동작 점수 = 기본 + 이벤트 사전값 + 기분(기준값 대비) + 반응 + 0.3·log(P_Jev + 0.05). Jev 영향은 최대 약 0.9로 묶인다. 상세: [스펙](../superpowers/specs/2026-10-16-action-model-design.md).

## 대안

- 보정 가중치만 키우기: Jev 차이가 크면 여전히 묻히고, 0.5 기준이라 성격이 늘 보정을 받는다.
- Jev 없이: 메시지 내용("앉아!")을 반영하지 못한다.

## 결과

- 시뮬레이션에서 가장 흔한 동작 비율이 0.40 안팎(목표 ≤ 0.50). 시뮬레이션 지표 "Jev 1위 동작 유지"를 "가장 흔한 동작 비율"로 바꿨다.
