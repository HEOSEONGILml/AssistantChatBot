# 0003. Windows에서 배경 모드와 오버레이 모드를 모두 지원하고, 사용자 설정으로 고정한다

- 상태: 채택 (배경 모드 구현 방식은 [0009](0009-background-mode-wallpaper-replacement.md)로 수정)
- 날짜: 2026-10-14

## 배경

Windows에서 캐릭터를 둘 곳은 두 가지다.

- **배경 모드**: 바탕화면 아이콘 뒤 레이어. 진짜 배경화면처럼 보이지만, 다른 창에 가려지고 직접 입력을 받기 어렵다.
- **오버레이 모드**: 항상 위에 떠 있는 투명 창. 언제나 보이고 바로 상호작용할 수 있지만, 작업 화면을 가릴 수 있다.

## 결정

두 모드를 모두 지원한다. 어느 모드를 쓸지는 사용자 설정으로 고정한다.
캐릭터가 말을 걸거나 사용자가 불러도 모드가 자동으로 바뀌지 않는다. 사용자가 지정한 사항이다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 배경 모드만 | 컨셉에 가장 충실하다 | 작업 중에는 캐릭터의 말을 보지 못한다 | 사용자가 둘 다 지원을 선택했다 |
| 오버레이 모드만 | 상호작용이 쉽다 | 작업을 가린다 | 사용자가 둘 다 지원을 선택했다 |
| 평소엔 배경, 상호작용할 때만 앞으로 | 두 장점을 섞는다 | 화면이 예측하기 어렵게 바뀐다 | 사용자가 설정 고정을 선택했다 |

## 결과

- 캐릭터의 움직임, 렌더링, 대화 로직은 두 모드가 공유한다. 모드마다 다른 것은 창을 어디에 두고 입력을 어떻게 받는가뿐이다.
- 배경 모드에서는 캐릭터가 창에 가려질 수 있다. 이때 선발화나 끼어들기를 어떻게 알릴지 정해야 한다 (미정).
- 배경 모드에서는 캐릭터를 직접 클릭하기 어렵다. 입력 수단을 따로 정해야 한다 (미정).
