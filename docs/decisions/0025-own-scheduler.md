# 0025. 스케줄 작업은 직접 구현한다

- 상태: 채택
- 날짜: 2026-10-21

## 배경

사용자가 자동화 스케줄을 염두에 두기로 했다.

screenpipe에는 pipes가 있다. 마크다운 파일 하나에 지시문과 스케줄을 적으면 정해진 시간에 Claude Code 같은 코딩 에이전트를 돌려 화면 기록을 조회하고 행동한다 (screenpipe README, 2026-10-21 확인).

## 결정

스케줄링은 직접 구현한다. 사용자가 정했다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| screenpipe pipes | 이미 있다. 1단계에 바로 쓴다 | 결과가 우리 출력 계층을 거치지 않는다 | 사용자가 직접 구현을 골랐다 |

## 결과

- 스케줄 작업의 구조(무엇을 저장하고, 어떻게 깨우고, 사용자가 없을 때 어떻게 하는지)는 설계에서 정한다.
