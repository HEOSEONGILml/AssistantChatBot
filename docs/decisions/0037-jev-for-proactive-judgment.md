# 0037. 먼저 말 걸기의 "헤매고 있나" 판단은 Jev로 한다

- 상태: 채택
- 날짜: 2026-10-22
- 수정: [0022](0022-pivot-to-assistant.md)의 "지금은 Jev를 쓰지 않는다"를 먼저 말 걸기 판단에 한해 바꾼다

## 배경

먼저 말 걸기([설계](../superpowers/specs/2026-10-22-proactive-help-design.md))는 사용자가 헤매고 있는지를 계속 판단해야 한다. 30초마다 판단하므로 빠르고 싸야 한다.

## 결정

판단은 Jev가 한다 (사용자: "판단에는 Jev가 빠르고 비용도 덜 들겠지"). 키는 설정 탭에서 입력한다 (사용자).

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| Claude Code로 판단 | 화면 이미지까지 볼 수 있다 | 짧은 답도 4~8초(2026-10-22 측정), 구독 사용량을 씀 | 30초마다 부르기엔 느리고 비싸다 |
| 간단한 규칙(같은 창 N분) | 비용 0 | "헤맨다"를 구분하지 못한다 | 사용자가 Jev를 골랐다 |

## 결과

- Jev는 판단 확률만 준다. 제안 글은 [도와줘]를 누를 때 Claude가 만든다 (CLAUDE.md 4절).
- 응답 70~500ms, 입력 100만 토큰당 $0.042는 업체 발표 값이다. 독립 검증하지 않았다 ([레퍼런스](../references/typesafe-jev.md)).
- Jev는 글만 받으므로 화면 기록의 글(OCR·접근성·창 제목)로 판단한다.
