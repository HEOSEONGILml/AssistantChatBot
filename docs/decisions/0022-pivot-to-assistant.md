# 0022. 다마고치를 접고 브라우저를 조작하는 조수로 바꾼다

- 상태: 채택
- 날짜: 2026-10-21
- 대체: 0001~0021 전부 (파일은 지웠다. git 기록 `4b8c747`에 있다)

## 배경

사용자가 프로젝트 성격을 다마고치에서 조수로 바꾸기로 했다. 강아지는 한 자리에서 사용자의 요청을 받아 대답하거나 실제 작업을 한다. 첫 기능은 사용자가 보고 있는 브라우저 창을 조작하는 것이다 ([vision](../vision.md)).

기존 코드와 문서의 대부분은 기분·반응·상호작용·Jev 분포 모형·웹 버전을 위한 것이라 새 방향에 쓰이지 않는다.

## 결정

조수와 무관한 코드와 문서를 지운다. 화면 ↔ 두뇌 껍데기만 남기고 설계를 처음부터 다시 한다. 이전 결정 기록은 모두 다마고치를 전제로 쓰여 있어 지운다.

남긴 것:
- 화면: Tauri 셸(트레이, 두뇌 띄우기), 두뇌 연결, 입력창, 키 설정 창, 기본 강아지 스프라이트
- 두뇌: 키 보관(`config.py`), WebSocket 전송(`server.py`), 빈 두뇌 핵심(`core.py`)
- 참고 문서: Jev API 요약(`references/typesafe-jev.md`)

이전 결정 중 계속 따르는 원칙:

| 원칙 | 누가 정했나 | 원래 기록 |
|---|---|---|
| Windows PC를 먼저 만든다. Android는 사용자가 지시할 때 한다 | 사용자 | 0002 |
| 화면은 Tauri(Rust + TypeScript), 두뇌는 PC 안에서 도는 파이썬 프로세스다 | 사용자 | 0008, 0011 |
| 두뇌는 화면에 의존하지 않는다. 혼자 실행되는 localhost WebSocket 서비스이고, 토큰으로 화면을 확인한다 | 원칙은 사용자, 방식은 Claude | 0012 |
| 중계 서버 없이 사용자가 넣은 API 키로 외부 AI를 직접 부른다. 키는 두뇌가 OS 자격 저장소에 둔다 | 사용자 | 0006, 0012 |

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 기존 코드를 두고 조수 기능을 덧붙인다 | 지우는 작업이 없다 | 쓰지 않는 코드와 문서가 설계를 흐린다 | 사용자가 삭제를 지시했다 |
| 새 저장소에서 시작한다 | 깨끗하다 | 쓸 만한 껍데기와 기록을 잃는다 | 껍데기(전송·키 보관·Tauri 셸)는 그대로 쓸 수 있다 |

## 결과

- 프로토콜을 v5로 올리고 최소 메시지(`hello`, `message`, `set_key`, `status`)만 남긴다. 두뇌는 받은 말을 아직 처리하지 않는다.
- 두뇌 의존성에서 `typesafe-sdk`, `google-genai`를 뺐다. 필요하면 설계 후 다시 넣는다.
- 키 이름(TypeSafe, Gemini)은 아직 그대로다. 조수가 쓸 LLM을 정할 때 다시 본다.
- 앱 이름·식별자(`TamagotchiChatBot`, `com.tamagotchi.app`)는 그대로다. 바꾸면 데이터 폴더와 자격 저장소 이름도 바뀌므로 따로 정한다.
