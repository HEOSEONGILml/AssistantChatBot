# 0019. 메시지 기분은 Jev 질문 하나로, 의도·시킨 동작 질문은 없앤다

- 상태: 채택
- 날짜: 2026-10-20

## 배경

메시지 하나의 기분 변화가 8단계를 거쳤다: 우리 값, Jev 오름·내림, 의도 질문 넷(속상함·달램·조용히 부탁·모진 말)으로 고치기, 크기 조정, 달램, 반대 기분 억제 30%, 여유 비례 반영, 말로 내리는 상한. 대부분 검수 회차마다 붙인 예외였다. 사용자가 이 구조를 원하지 않았다 (2026-10-20).

## 결정

- 글이 없는 사건(찌르기·쓰다듬기·던지기·돌아옴·집에서 나옴·조용함 등)은 우리 모형 값만 쓴다.
- 메시지·타이핑은 Jev 질문 하나 "이 말이 강아지에게 어느 기분을 일으키나"(기분 9개 + 없음)만 쓴다. 변화 = 0.3 × P(기분).
- 그 뒤 반대 기분 억제만 한다. 한쪽이 오른 만큼 반대쪽을 같은 양 내린다. 결과는 0~1로 자른다.
- 의도 질문 넷과 시킨 동작 질문을 없애고, 그것들이 쓰이던 곳도 없앤다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택하지 않은 이유 |
|---|---|---|---|
| 오름·내림 19개 선택지 | 말로 기분을 직접 내릴 수 있다 | 선택지가 많다 | 사용자가 9개 + 없음을 골랐다. 내림은 반대 기분 억제와 시간이 맡는다 |
| 의도 질문을 남겨 말하기·대사에만 쓰기 | "말 걸지 마"·위로 같은 대화 흐름이 남는다 | 질문과 규칙이 많다 | 사용자가 전부 없애기로 했다 |
| 시킨 동작 질문 남기기 | "앉아"를 잘 따른다 | 질문 하나 더 | 사용자 결정. 동작 질문(Jev 무게 1.5)이 일부 맡는다 |

## 결과

- Jev 질문은 동작·말하기·기분 셋이다.
- 사라지는 동작: "말 걸지 마" 1시간 조용, "잘 자" 잠자리, 사과에 꼭 대답, 시킨 동작 따르기, 대사의 "속상해 보인다"·"모진 말"·"부탁"·"시킨 것을 했다" 사실, 핀잔 뒤 이어 말하지 않기, 공감·달램·경계로 기분 고치기, 잡음, 여유 비례, 말로 내리는 상한.
- 질문이 바뀌었으므로 Jev를 다시 녹화하고 보정값을 다시 맞춘다.
